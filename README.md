# 文献研究 Agent（dsh-litkb）

> 装进 DeepSeek Harness 的本地文献知识库：收文 → 精读/七段卡 → 证据链 → 横向对比/图谱 → 可追溯问答 → 写作。

**版本**：**0.1.0**  
**状态**：P0–P4.11 完成，场景补齐（链接导入 / 横向精读 / 9 个 Agent 工具）已收口。

## 核心场景

| 场景 | 现在能做什么 |
|---|---|
| 收文 | 本地 PDF 拖拽/多选；DOI / arXiv / 普通 PDF 链接导入；SHA 去重；失败提示 |
| 解析 | PaddleOCR / pdf.js；分页分块；页图；解析稿；整篇/章节/块翻译；术语表 |
| 七段卡 | 生成、逐段编辑、逐段/整卡重生成、批注、版本回滚、q-id 证据 |
| 精读 | 11 板块 Markdown、数值核对、论点候选、q-id 回贴；左侧小节导航可隐藏 |
| 证据链 | 四种手动建链；单篇自动建链草稿；跨论文对比/矛盾链（字面 + 主题/概念强配对）；审核队列 |
| 图谱 | 证据链知识库：Cytoscape、10 字节点、分色、拖拽、布局持久化；概念图谱暂时隐藏 |
| 横向精读 | 独立页签；2–4 篇并排；差异/数字高亮；只看差异；折叠；对比链；存为文稿 |
| 检索问答 | BM25 证据/链检索；链优先答案；q-id 引用校验；过滤/复制/存为文稿；最近 50 条历史 |
| 写作 | 文稿 CRUD、引用库、参考文献、AI 扩写意图、可拖拽三栏、专注模式、MD 导出 |
| Agent | 9 个 `lit_*` 工具；读优先，保存链必须 `confirm:true` |
| 导出 | BibTeX、GB/T、证据 JSON/CSV、卡片 MD、图谱 Mermaid/Canvas、解析稿 MD |

## 界面导航

```text
论文库 / 横向精读 / 图谱 / 写作 / 检索
```

- 论文库：列表 + 详情 + 原文；详情页签为 详情 / 七段卡 / **精读** / 原文解析；
- 论文行右侧（选中或 hover）：**自动建链 / 审核**；
- 图谱页：证据链知识库 + 自动建链/审核（整库或跨论文）；
- 横向精读：独立页签；
- 概念图谱：**暂时隐藏**，组件与 `/graph` 接口保留。

## 运行

- 数据目录：默认 `~/Documents/文献库`，可用 `LITKB_LIBRARY` 覆盖；
- 安装：把 `dsh-litkb-0.1.0.tgz` 安装到 DSH profile（当前工作区为 link 安装），**完全重启 DSH**；
- 前端缓存：重启后 `Cmd+Shift+R`；
- 健康检查：`GET /api/litkb/health` 应显示 `0.1.0`。

## 开发

```bash
npm run build     # 从 src/ 生成 lib/
npm test          # 116 项
npm run check     # 所有服务端模块语法检查
npm pack          # 产出 dsh-litkb-0.1.0.tgz
```

目录：

```text
lib/         服务端 + 客户端（单文件 React，无构建步骤）
prompts/     prompt 版本化
tests/       假 React / 临时库 / 真实库干跑
docs/        方案、交付单、验收记录、对照图
docs/assets/ 截图与架构图
```

## 关键边界

- 自动建链是草稿 + 审核，不直接污染正式链库；
- 无精读时用七段卡兜底，并提示补精读复核；
- 跨论文链是规则判断（相似度/数字/线索词/主题/概念），低置信度会警告；
- 检索答案必须带库内 q-id；无模型时退化为抽取式，不编造；
- 概念图谱暂隐藏；LLM 重排、文件夹监控、整库 vault 导出未做。
