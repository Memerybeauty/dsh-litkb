# 安装、升级与发布（v0.2.0）

## 安装

1. 使用发布包 `dsh-litkb-0.2.0.tgz`，或从 GitHub 仓库获取源码：

```bash
git clone https://github.com/Memerybeauty/dsh-litkb.git
cd dsh-litkb
npm install
npm run build
npm test
npm pack
```

2. 将包/工作区安装到 DSH profile（当前开发环境为 link 安装）；
3. **完全退出 DSH 再启动**；
4. 浏览器 `Cmd+Shift+R`；
5. 检查：

```bash
curl http://127.0.0.1:<当前端口>/api/litkb/health
# 应显示 "version":"0.2.0"
```

> 只刷新页面不会注册新的服务端路由或 Agent 工具。

## 升级

1. 备份 `~/Documents/文献库`（至少 `cards/`、`chains/`、`drafts/`、`concepts/concepts.json`）；
2. 替换包/更新 link；
3. `npm run build && npm test`（源码安装时）；
4. 重启 DSH + 强刷；
5. 检查 `/health` 与启动日志中的 Agent tools 数量。

## 发布流程

```bash
# 1. 版本号
# package.json / dsh.plugin.json / package-lock.json -> 0.2.0

# 2. 构建 + 测试
npm run build
npm test
npm run check

# 3. 打包
npm pack
# -> dsh-litkb-0.2.0.tgz

# 4. Git
git add .
git commit -m "release: v0.2.0"
git tag -a v0.2.0 -m "dsh-litkb v0.2.0"
git push origin main
git push origin v0.2.0

# 5. GitHub Release（附加 tgz）
gh release create v0.2.0 dsh-litkb-0.2.0.tgz \
  --title "dsh-litkb v0.2.0" --notes-file CHANGELOG.md
```

## 回滚

- 代码：`git checkout v0.2.0` / 安装上一版 tgz；
- 数据：库是文件，恢复备份的 `cards/`、`chains/`、`drafts/`、`concepts/` 即可；
- 不要删除 `concepts/concepts.json` 与 `cards/`（人工资产）。
