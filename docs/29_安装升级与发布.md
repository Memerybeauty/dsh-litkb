# 安装、升级与发布（v0.16.0）

## 1. 安装

### 1.1 从源码（当前开发方式）

```bash
git clone https://github.com/Memerybeauty/dsh-litkb.git
cd dsh-litkb
npm install
npm run build
npm test
npm run plugin:install -- --profile desktop --link
```

`--link` 把 profile 指向当前工作区，改完源码只需重启 DSH；不带 `--link` 则用打包后的 tgz。

### 1.2 从发布包

```bash
npm run plugin:install -- --profile desktop --tgz ./dsh-litkb-0.16.0.tgz
```

安装器会：

1. 写 `~/.dsh/profiles/<profile>/package.json` 的 `dependencies["dsh-litkb"]`；
2. 确保 `dsh.profile.bundles` 含 `dsh-litkb`；
3. 备份原 manifest 为 `package.json.bak-litkb`；
4. 执行 `pnpm install --prefer-offline`，失败自动还原。

其他参数：

| 参数 | 说明 |
|---|---|
| `--profile <name>` | `desktop`（默认）/ `web`，也接受绝对路径 |
| `--tgz <path>` | 指定 tgz；缺省找 `dsh-litkb-<version>.tgz`，没有就 `npm pack` |
| `--link` | 开发模式，安装 `link:<工作区>` |
| `--dry-run` | 只打印计划 |
| `--pnpm <path>` | 指定 pnpm |
| `--skip-install` | 只改 manifest，不执行 pnpm |

### 1.3 安装后

1. **完全退出 DSH**（不是关窗口）再启动；
2. 浏览器 `Cmd+Shift+R`；
3. 检查：

```bash
curl http://127.0.0.1:<端口>/api/litkb/health
# 应显示 "version":"0.16.0"
```

> 只刷新页面不会注册新的服务端路由或 Agent 工具。

## 2. 升级

1. **先备份**：设置 → 文献工作台 → 数据与备份 →「下载整库备份」；
2. 拉取新代码 / 新 tgz；
3. `npm run build && npm run verify`（源码安装时）；
4. `npm run plugin:install -- --profile desktop`；
5. 完全重启 DSH + 强刷；
6. 检查 `/health` 版本、设置页「关于」、页脚版本号；
7. 抽查：论文列表、卡片、证据链、研究、文稿各开一条。

升级不会改写库结构；`index.jsonl` 会在读取时兼容旧字段。

## 3. 回滚

- 代码：`git checkout v0.10.0` 或安装上一版 tgz，然后重启；
- 数据：设置 → 数据与备份 →「从备份恢复…」选择升级前的 zip；
- 恢复前会自动把当前库快照到 `cache/backups/pre-restore-<时间>.zip`；
- 不要手动删 `cards/`、`chains/`、`drafts/`、`themes/`。

## 4. 发布流程

```bash
# 1. 版本号：package.json / package-lock.json / dsh.plugin.json -> 0.16.0
npm version 0.16.0 --no-git-tag-version

# 2. 构建 + 质量门
npm run build
npm run verify
npm run coverage

# 3. 打包
npm pack
# -> dsh-litkb-0.16.0.tgz

# 4. Git
git add .
git commit -m "release: v0.16.0"
git tag -a v0.16.0 -m "dsh-litkb v0.16.0"
git push origin main
git push origin v0.16.0

# 5. GitHub Release（附加 tgz）
gh release create v0.16.0 dsh-litkb-0.16.0.tgz \
  --title "dsh-litkb v0.16.0" --notes-file CHANGELOG.md
```

## 5. 卸载

```bash
# 1. 从 profile 移除
cd ~/.dsh/profiles/desktop
pnpm remove dsh-litkb
# 如手工改过 package.json，删掉 dependencies["dsh-litkb"] 与 bundles 里的 dsh-litkb

# 2. 重启 DSH
# 3. 数据目录不会自动删除；确认备份后再手动处理
rm -rf ~/Documents/文献库   # 危险，先确认
```

## 6. 产物与端口

- 安装包：`dsh-litkb-0.16.0.tgz`；
- 库目录：默认 `~/Documents/文献库`，`LITKB_LIBRARY` 可覆盖；
- 端口：DSH Web 启动时打印；桌面端每次启动可能不同；
- 健康检查：`/api/litkb/health`；诊断：`/api/litkb/diag`。
