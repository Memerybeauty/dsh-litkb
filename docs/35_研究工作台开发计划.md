## 9. 风险与应对

| 风险 | 概率 | 应对 |
|---|---|---|
| `search.js` 重构影响检索 | 中 | 先加行为回归；不行就复制打分函数，不动 search |
| 6 个页签窄屏溢出 | 中 | 1280/1024 实测；溢出改「工作台」文案或收进更多 |
| 研究页信息过载 | 高 | 三段折叠，默认只展开研究内容 |
| 文稿绑定悬空（draft 被删） | 低 | `read` 时校验 `draftId`，失效则清空并提示重建 |
| 任务轮询状态错乱 | 低 | 复用现有 job 模式，前端只认 `jobId` |
| 文档与实现脱节 | 中 | P5.4 固定同步 19/27/28/30/32，版本号一次改全 |

**回滚**：功能全程走新文件 + 新路由，不改旧链路；出问题可删 `themes/` 与两个新片段，回退到 v0.1.2。

## 10. 发布清单（v0.2.0）

1. `npm run build` → `npm run check` → `npm test`；
2. `npm pack` → `dsh-litkb-0.2.0.tgz`；
3. 安装到 profile，**完全重启 DSH**；
4. `GET /api/litkb/health` 显示 `0.2.0`；
5. 前端 `Cmd+Shift+R`；
6. 冒烟：建研究 → 匹配 → 生成 → 审核 → 提纲 → 写作页；
7. 更新 `CHANGELOG.md` 与 `docs/32`。

## 11. 本轮不做

- 主题自动发现/聚类；
- 向量检索、LLM 重排；
- 自动写整篇初稿（只到提纲 + 引用）；
- 整库 vault / 双语导出；
- 多用户、移动端；
- 主题模板市场、主题分享。
