## 链（chains/<id>.json）

```json
{
  "id": "c-1a2b3c4d",
  "title": "极坐标改善视盘边界",
  "origin": "claim | evidence | question | block | auto | topic",
  "status": "draft | confirmed",
  "confidence": 0.9,
  "topic": "视盘分割",
  "paperIds": ["p-..."],
  "claim": { "text": "...", "paperId": "p-...", "sectionKey": "...", "source": "..." },
  "nodes": [
    { "id": "n-...", "relation": "supports", "paperId": "p-...", "evidenceId": "q-...",
      "page": 5, "block": "b-...", "quote": "...", "note": "" }
  ],
  "provenance": {
    "runId": "run-...", "model": null, "promptVersion": "chain-auto.v1",
    "source": "deepread | card", "sections": ["conclusion"],
    "strongPair": { "kind": "topic | concept", "key": "...", "similarity": 0.03 }
  },
  "warnings": [],
  "review": null
}
```

硬规则：

- 节点只能来自库内 q-id；没有证据不建链；
- 自动链默认 `status=draft`，审核后 `confirmed`；
- 跨论文链 `provenance.kind=cross-paper`，低置信度带 warning；
- `strongPair` 表示主题/概念强配对，需人工重点核对；
- 主题链 `origin=topic`，`provenance.themeId + facetKey` 是幂等键：已有 draft 原地更新，confirmed 不覆盖。

## 研究（themes/<id>.json）

```json
{
  "id": "t-1a2b3c4d",
  "title": "多模态大模型在医学影像诊断中的应用",
  "description": "综述第二章",
  "tags": ["医学影像"],
  "facets": [
    { "key": "f1", "title": "多模态融合方式", "description": "…",
      "keywords": ["fusion", "融合"], "mode": "compare | verify", "enabled": true }
  ],
  "papers": {
    "include": ["p-..."], "exclude": ["p-..."],
    "lastMatch": { "at": "…", "papers": [{ "paperId": "p-...", "score": 4.2, "facets": ["f1"], "hits": 7 }] }
  },
  "match": {
    "minScore": 1.5, "relative": 0.4, "perPaper": 2,
    "maxHits": 8, "maxPapers": 6,
    "keywordMode": "require", "tagMode": "boost",
    "yearFrom": 0, "yearTo": 0, "expand": true
  },
  "draftId": "d-...",
  "summary": { "text": "", "updatedAt": null, "model": null,
               "basis": { "chainIds": ["c-..."], "fingerprint": "sha1..." } },
  "createdAt": "…", "updatedAt": "…",
  "lastRun": { "runId": "run-theme-…", "at": "…", "matcher": "theme-match.v1", "model": null }
}
```

规则：

- `facets[].key` 创建时生成，编辑标题不改 key（链的幂等键）；
- `papers.include/exclude` 是人工覆盖，派生命中不落盘；
- `summary.text` 非空表示人工改过，重跑不覆盖；
- 链状态不存主题文件，按 `provenance.themeId` 反查；
- 删除研究不删链与文稿。

## 链接导入

`index.jsonl` 中该记录的 `source` 为 `link`，并带：

```json
{ "importedAt": "ISO", "importedFrom": "https://..." }
```

DOI 元数据来自 Crossref（title/authors/year/venue/doi），PDF 解析仍走标准卡片管线。

## 迁移

- 0.28.x 内部数据 → 0.1.2 没有破坏性变更；旧 `chains` 缺 `confidence/provenance` 时按默认值读取；
- 0.1.2 → 0.2.0 新增 `themes/` 目录与 `origin=topic` 的链；旧库无需迁移，首次进入研究工作台自动建目录；
- 旧的 `litkb.conceptPositions`（v1）已被 `litkb.conceptPositions.v2` 取代，旧坐标可忽略；
- 升级前备份人工资产；不要手改 `index.jsonl`（可重建但需保留 id）。
