## 0. 为什么现在必须先做写作

反链现在无法验收，不是反链坏了，而是**库里没有可引用的文稿**：

- 反链扫的是 `cards/*.md` 与 `exports/*.md`；
- 目前 `exports/` 是空的，卡片之间也很少互相引用；
- 所以所有证据都显示「未被引用」。

继续补反链、图谱、追问，都只是在「读」上打转。真正缺的是：

> **把读到的证据，变成自己文章里的一句话。**

所以下一版先做**写作工作区**，优先级高于检索、Agent 工具。

## 2. 产品形态：第三个页签

顶部从「论文库 / 图谱」增加为：

**论文库 ｜ 写作 ｜ 图谱**

写作页也是三栏，和阅读页保持一致：

```
┌──────────────────┬──────────────────────────────────┬──────────────────┐
│ 文稿 280         │ 写作区                           │ 引用/素材/检查 360│
│ ＋ 新建文稿       │ 《标题》 草稿 · 1,240 字 · 8 引用 │ [引用库][素材][检查]│
│ ─────────────    │                                  │                  │
│ ▸ 开题_研究现状   │ ## 1. 研究现状                    │ 搜索证据…         │
│ ▸ 综述_方法       │ 视盘分割方法经历了从 U-Net 到…    │ ▸ p.5 引文…       │
│ ▸ 笔记_xxx        │ [[p-x#^q-y|Wu 2026, p.5]]         │ [插入引用]        │
│                  │                                  │ ─────────────     │
│ 素材篮            │                                  │ 已引用 8 篇       │
│ ▸ 未归档引文 12   │                                  │ 未引用断言 2 处   │
└──────────────────┴──────────────────────────────────┴──────────────────┘
```

- 左栏：文稿列表 + 新建；
- 中栏：Markdown 编辑器（标题 + 正文），顶部工具栏（H2、粗体、列表、插入引用、预览）；
- 右栏：
  - **引用库**：全库证据搜索，点「插入引用」；
  - **素材**：从卡片/追问/可比组收集来的素材；
  - **检查**：未引用断言、参考文献、导出。

---

## 3. 核心闭环

```
读论文
  → 证据旁「引用」/「存入素材」
  → 写作区插入到光标
  → 继续写
  → 检查未引用断言
  → 生成参考文献
  → 导出 Markdown / 交给 Word
```

### 3.1 从证据到文稿

在七段卡/右栏证据旁增加两个动作：

| 动作 | 行为 |
|---|---|
| **引用** | 插入 `[[p-xxx#^q-xxxx\|作者 年, p.N]]` 到当前文稿光标处；没有文稿就新建 |
| **存入素材** | 存进写作页「素材篮」，不直接进正文 |

### 3.2 文稿格式

纯 Markdown，Obsidian 兼容：

```markdown
---
title: 开题_研究现状
type: 综述
status: 草稿
created: 2026-11-05
updated: 2026-11-05
---

## 1. 研究现状

视盘分割从 U-Net 发展到极坐标变换与拓扑约束 [[p-1e4cbf07#^q-76c232f2|Wu 2026, p.5]]。
```

- `[[paper#^q-id|显示文本]]` 是引用块，Obsidian 可直接跳转；
- 反链扫描器增加 `drafts/`，证据旁就能看到「被哪篇文稿第几行引用」；
- 文稿不进入 `cards/`，避免与论文卡混在一起。

### 3.3 检查

- **未引用断言**：段落里的事实句没有 `[[...]]` 或 `[p.N]` 时标黄；
- **页码检查**：引用页码必须在对应证据里存在；
- **参考文献**：从文稿引用去重，生成 BibTeX / GB/T；
- **导出**：Markdown（默认）、复制到剪贴板、后续 DOCX。

## 4. 数据与接口

### 4.1 文件

```
文献库/
├── drafts/
│   ├── d-xxxx.md          # 文稿真源（frontmatter + 正文）
│   └── .versions/         # 保存前快照（可选）
├── exports/               # 仍放导出的成品
```

- `drafts/*.md` 是用户资产，不随插件卸载删除；
- 反链扫描范围扩展为 `cards/`、`drafts/`、`exports/`；
- 文稿 ID `d-` + 8 位哈希/时间戳。

### 4.2 API

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/litkb/drafts` | 文稿列表（标题/字数/引用数/更新时间） |
| POST | `/api/litkb/drafts` | 新建文稿 |
| GET | `/api/litkb/drafts/:id` | 读文稿 |
| PUT | `/api/litkb/drafts/:id` | 保存（自动保存也走这里） |
| POST | `/api/litkb/drafts/export` | 导出 Markdown + 参考文献 |
| GET | `/api/litkb/drafts/citations` | 文稿引用解析/参考文献 |

### 4.3 自动保存

- 输入后 1.5 秒防抖保存；
- 显示「保存中 / 已保存 HH:mm」；
- 保存前写 `.versions/` 快照，保留最近 20 份；
- 页面关闭前未保存时提示。

## 7. P4.7 验收

1. 写作页新建文稿，写 2 段；
2. 从两篇论文的 3 条证据点「引用」，引用出现在光标处；
3. 关掉再打开，文稿与引用还在；
4. 回到证据，点「反链」，能看到 `drafts/xxx.md:12`；
5. 点反链行号能打开文稿对应位置；
6. 导出 Markdown，Obsidian 打开可跳引用；
7. 素材篮至少能收 1 条追问答案/证据。

---

## 8. 非目标（本阶段）

- 不做 Word 式富文本、批注、修订模式；
- 不做多人协作、云同步；
- 不做整篇 AI 代写；
- 暂不做 DOCX / LaTeX 导出（P4.8 后评估）；
- 不改卡片与证据的数据结构。

---

## 9. 风险与取舍

| 风险 | 对策 |
|---|---|
| 编辑器体验差 | 先 Markdown 文本域 + 预览；不做复杂富文本 |
| 引用格式不统一 | 只认 `[[paper#^q-id]]`，写入时固定生成 |
| 反链扫描变慢 | 只扫 `cards/`、`drafts/`、`exports/` 一层，按 mtime 缓存 |
| 自动保存冲突 | 单用户，最后写入胜出；保存前快照 |
| AI 编造引用 | AI 只允许引用已有证据；生成段落标「AI 草稿」 |

1. **写作页位置**：A 顶部第三个页签「写作」（推荐）／B 只在论文库里加「写作」抽屉；

3. **首版范围**：A 只做 P4.7 MVP（推荐）／B MVP + 引用库搜索 + 参考文献一起；
