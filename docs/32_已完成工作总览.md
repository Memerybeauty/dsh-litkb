## 2. 现在能做什么（按用户动作）

| 动作 | 入口 | 结果 |
|---|---|---|
| 收一篇论文 | 论文库拖拽 / 「＋ 导入 PDF」/「链接 · DOI」 | 去重、分类打标、解析、建卡片骨架；失败可见可重试 |
| 读懂一篇 | 详情 → 七段卡 / 精读 | 七段摘要 + 11 板块精读，结论带 q-id 可跳原文 |
| 核对一句话 | 任意 `p.N` / q-id | 打开页图并高亮对应块；块失效时显式提示 |
| 建一条论证链 | 精读论点 / 解析稿段落 / 证据行 → 建链 | claim–evidence 链落盘，可插入文稿并复用到参考文献 |
| 批量出草稿 | 论文行「自动建链」/ 图谱页整库 | 自动草稿进审核队列，确认后才进图谱与检索 |
| 横向比几篇 | 顶层「横向精读」 | 2–4 篇并排，差异/数字高亮，可生成对比链 |
| 找一句话的出处 | 顶层「检索」 | BM25 链级答案 + 引用校验 + trace；无模型退化为抽取式 |
| 写综述 | 顶层「写作」 | 文稿 CRUD、引用库、GB/T 参考文献、按证据 AI 扩写、Markdown 导出 |
| 让 Agent 帮我查 | DSH 对话内 12 个 `lit_*` 工具 | 读优先；保存链/主题建链必须 `confirm:true` |
| 导出 | 卡片 / 列表 / 图谱 | BibTeX、GB/T、证据 JSON/CSV、卡片 MD、Mermaid/Canvas、解析稿 MD |
