## 1. 这一版做了什么

| # | 能力 | 说明 |
|---|---|---|
| 1 | 上下文 | 每条证据可展开 `before / after`（各约 90 字），防断章取义 |
| 2 | 块断链 | 证据指向的版面块不存在时标「块已失效」，仍可按页定位，不静默 |
| 3 | 块修复 | 块 ID 失效但引文还能在新解析稿里找到时，自动指到新块（只读时修复） |
| 4 | 反链 | API 已实现；**UI 按反馈隐藏，P4 再开放**（当前阶段还没有草稿，按钮会一直为空） |
| 5 | 导出 | 单篇证据导出 JSON / CSV（论文、页码、块 ID、引文、上下文、段落） |
| 6 | 免责 | 反链只扫库内 Markdown，不扫外部 Obsidian vault；P2 不展示入口 |

**没有**：图表号自动识别、跨论文断言图（Claim）、证据高亮持久化到卡片 JSON。

---

## 2. 接口

| 接口 | 行为 |
|---|---|
| `GET /evidence/backlinks?id=q-xxxxxxxx&paper=p-x` | 返回 `{links:[{file,line,text}]}`；排除证据自己的卡片 |
| `GET /evidence/export?id=p-x&format=json` | 下载 JSON（paper/exportedAt/evidence[]） |
| `GET /evidence/export?id=p-x&format=csv` | 下载 CSV（UTF-8 BOM，Excel 中文不乱码） |

`GET /card` 的每条证据新增：

- `blockMissing: true`（块不存在且无法修复）；
- `blockRepaired: true`（块 ID 已按引文重新指向）；
- `before / after` 原样返回。

## 4. 你要做的初验（4 条）

> ⌘Q 退出 → 重新打开（版本 **0.4.3**）。

| # | 操作 | 通过标准 |
|---|---|---|
| 1 | 七段卡点某条证据「上下文」 | 展开前后各一段；再点收起 |
| 2 | 点「导出 JSON / CSV」 | 浏览器下载文件；CSV 用 Excel 打开中文正常 |
| 3 | 重建解析稿后打开卡片 | 块 ID 变了会尝试修复；修不了显示「块已失效」，仍能按页跳转 |

## 5. 已知限制

| 限制 | 说明 | 计划 |
|---|---|---|
| 反链 UI | 已实现但隐藏，P4 写综述时再开放 | P4 |
