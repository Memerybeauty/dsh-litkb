# 研究模板、双栏顺序与逐段精读（v0.10）

| 项 | 内容 |
|---|---|
| 状态 | 已实施（v0.10.0） |
| 目标 | 降低建研究成本；修双栏阅读顺序；精读可逐段编辑 |

## 1. 研究模板

新建研究弹窗顶部：

```text
模板  [综述] [开题] [方法对比]
```

| 模板 | 细分 |
|---|---|
| 综述 | 背景与问题 / 技术路线 / 代表性工作 / 数据与指标 / 挑战 / 趋势 |
| 开题 | 研究问题 / 现状 / 缺口 / 技术路线 / 实验计划 / 预期贡献 |
| 方法对比 | 任务 / 方法 A / 方法 B / 指标差异 / 边界与结论 |

套用模板只填充细分与描述，标题、标签仍可改；「AI 帮我拆」保留。

## 2. 从标签一键建研究

个人工作台标题栏「从标签建 ▾」：

- 列出库内标签（最多 20 个）；
- 点一个标签 → 以「标签名研究」为标题，标签作为绑定标签，预填四条细分：
  背景与问题 / 代表性方法 / 数据与评测 / 局限与趋势；
- 细分关键词自动填该标签，直接「开始探索」即可匹配。

## 3. 双栏阅读顺序

`lib/paragraphs.js` 的 `readingOrder(page)`：

1. 有 bbox 的块按宽度分「整宽」与「栏内」；
2. 整宽块作为分隔（标题/摘要/跨栏图表）；
3. 每个分隔区间内，先左栏按 y、再右栏按 y；
4. 无 bbox 或左右栏块不足 2 个时保持原顺序。

用于解析稿、卡片输入与建链语料。已知限制：整宽图表在页面中部时会被当作分隔，可能提前；后续可做更细的 band 模型。

## 4. 精读逐段编辑

精读每个板块标题右侧新增「编辑」：

- 点击变 textarea；
- 「保存本段」调用 `POST /deepread/section`，只改这一段 `markdown`，重算整篇 `markdown`；
- 其他板块、数值核对、claim 不受影响；
- 编辑时间写入 `editedAt`。

接口：

```http
POST /api/litkb/deepread/section
{ "id": "p-...", "key": "method", "markdown": "..." }
```
