# 故障排查

## 1. 新接口 404 / 工具不出现

- 原因：只刷新页面，服务端仍是旧进程；
- 检查：`GET /api/litkb/health` 的 version；
- 处理：完全退出 DSH（Cmd+Q）再打开，然后 `Cmd+Shift+R`。

## 2. 页面暗底暗字 / 弹窗透明

- 原因：客户端主题令牌没跟随宿主；
- v0.1.2 已通过 `litkb-theme-light/dark` 显式主题类修复；
- 仍有问题：强制刷新；确认没有多个 DSH 进程/旧端口。

## 3. 横向精读表格只显示几行

- v0.28.3 已修 `litkb-compareTable` 类名冲突；
- v0.1.2 源码中表类为 `litkb-compareGrid`；
- 若仍裁切，确认加载的是 0.1.2 客户端。

## 4. 概念图谱看不到

- 预期行为：v0.28.4 起 UI **暂时隐藏**；
- 数据与 `/graph` 接口保留，代码 `ConceptGraphPanel` 仍在。

## 5. 自动建链提示“没有精读”

- v0.27.2 起无精读会用七段卡兜底；
- 若仍报错，确认该论文至少有七段卡；
- 没有卡/精读时提示 `no_source` 是预期。

## 6. 链接导入没有 PDF

- 只接受开放可访问的 PDF；
- DOI 有元数据但无开放 PDF 时返回 `no_pdf`；
- 处理：下载 PDF 后本地导入，或直接贴 `citation_pdf_url`/PDF 链接。

## 7. Git push HTTP 400

- 本机曾因 HTTP 缓冲导致 5MB 首推失败；
- 可设置：`git config http.postBuffer 52428800`，再 `git push`。

## 8. 查看日志

- DSH 启动日志应有 `[dsh-litkb] plugin loaded v0.1.2`；
- 以及 `9 agent tools registered`；
- 端口以当前 Web GUI URL 为准，不要用旧端口。
