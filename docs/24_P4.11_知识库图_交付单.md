## 1. 为什么改

P4.10 之后，库里的「论证单元」已经是 `chains/<id>.json`：claim → evidence，关系分支持/反驳/限定。
但原来的「图谱」页画的是概念边（uses/improves_on/...），是手写 Canvas，不能拖、不能存布局，也看不到证据链。

这一版把「图谱」页首屏换成 **证据链知识库**：

```
claim（论点） ──支持/反驳/限定/推导/对比──> evidence（q-id 引文） ──出处──> paper（论文）
```

节点可以拖，画布可以缩放/平移，拖完的位置会保存；概念图谱作为第二个视图保留，可比组/待归一队列不受影响。

### 2.1 图数据

`GET /api/litkb/chains/graph`：

```json
{
  "generatedAt": "ISO",
  "stats": { "chains": 3, "claims": 3, "evidence": 10, "papers": 3, "staleEdges": 0 },
  "nodes": [
    { "data": { "id": "claim:c-xxx", "kind": "claim", "chainId": "c-xxx", "label": "…", "paperId": "p-x", "count": 4 } },
    { "data": { "id": "evidence:p-x:q-xxx", "kind": "evidence", "label": "…", "page": 5, "block": "b-x", "paperId": "p-x" } },
    { "data": { "id": "paper:p-x", "kind": "paper", "label": "…", "year": 2024 } }
  ],
  "edges": [
    { "data": { "id": "rel:c-xxx:q-xxx", "source": "claim:c-xxx", "target": "evidence:p-x:q-xxx", "kind": "supports", "label": "支持" } },
    { "data": { "id": "excerpt:p-x:q-xxx", "source": "evidence:p-x:q-xxx", "target": "paper:p-x", "kind": "excerpt" } }
  ],
  "positions": { "claim:c-xxx": { "x": 120, "y": 80 } }
}
```

- 同一个 q-id 被多条链引用时，图上只有一个 evidence 节点（汇聚）；
- 失效证据节点保留并标 `stale`，边画虚线；
- 论文节点由证据的 `paperId` 生成，label 取索引里的标题。

### 2.2 布局持久化

`POST /api/litkb/chains/layout`：

```json
{ "positions": { "claim:c-xxx": { "x": 120, "y": 80 } } }
```

- 落 `chains/.layout.json`（派生数据，可删；删了会重新布局）；
- 只接受 `[a-zA-Z0-9:_-]` 的节点 id 和有限数值，最多 2000 个；
- 拖动节点 600ms 后自动保存；首次进入用 `breadthfirst` 从 claim 出发布局；
- 新增链时保留已拖位置：新节点优先贴邻居，否则排到右侧空白区。

### 2.3 UI

- 「图谱」页顶部：**证据链知识库 / 概念图谱** 双视图；
- 证据链视图：统计（链/证据/论文/失效）、搜索、缩放、适应、重排、刷新；
- 点节点 → 右侧详情：
  - claim：打开链（弹窗）、看论文；
  - evidence：回原文（p.N + block）、看论文；
  - paper：打开论文；
  - edge：关系 + 两端节点；
- 空态：没有链时提示「去论文库建链」并一键切回论文库；
- 图引擎懒加载：首次进入才拉 `/api/litkb/vendor/cytoscape.js`，失败显示错误与重试。

## 4. 已知限制

| 限制 | 影响 | 后续 |
|---|---|---|
| 节点位置是全局坐标 | 不同窗口宽度下布局不自适应 | 可加「按视口适配」或归一化坐标 |
| 没有按关系/论文过滤 | 链多时图会密 | P4.11 加关系开关与论文聚焦 |
| 没有多选/框选 | 不能批量拖拽 | Cytoscape 支持 `boxSelectionEnabled`，按需开 |
| 不能从图里直接建链 | 需回到论文库/证据 tab | 可在侧栏加「以该论点为起点建链」 |
| 概念与证据链未合并 | 两个视图各看一半 | 后续做「概念→证据」钻取 |
| 图引擎脚本依赖同源路由 | 极端 CSP 下可能被拦 | 失败有错误提示，可改为内联包 |

## 6. 补：节点配色与 10 字摘要（v0.18.1，2026-11-05）

反馈：节点颜色要更清楚，节点内容不超过 10 个字，剩下的放详情，整体要更好看。

改动：

- 每个图节点增加 `short` 字段（中文 ≤10 字；英文 ≤14 字符），Cytoscape label 用 `short`；
  - 论点：去掉「作者结论是/研究表明」等前缀，取首个短句；
  - 证据：显示 `p.N 证据`；
  - 论文：显示「作者 年份」，缺字段回退标题；
- 完整文本放 `full`，右侧详情与悬停 tooltip 展示；搜索仍匹配全文；
- 节点配色：**论点蓝**（#1e3a8a/#60a5fa）、**证据绿**（#14532d/#4ade80）、**论文紫**（#4c1d95/#c084fc），
  证据用 `round-tag` 形状，论文用椭圆；失效节点黄色虚线；
- 关系边按支持/反驳/限定/推导/对比分色，标签同步着色；出处边灰色点线；
- 图例增加节点颜色；统计条按节点类型着色；画布加 22px 点阵背景；
- 悬停：节点描边加粗 + 跟随鼠标的 tooltip；点开右侧详情。

验证：`npm test` **90 项全过**；Cytoscape 无头校验无样式警告，三类节点背景色分别为
`rgb(30,58,138) / rgb(20,83,45) / rgb(76,29,149)`。

## 7. 补：全库论文都上图（v0.18.2，2026-11-05）

反馈：打开知识库为什么只有一篇论文？

排查：库里 4 篇论文，但 5 条证据链**全部建自 p-815555f5**（其余 3 篇还没有链）。
原图只画「有链的论文」，所以只剩 1 个论文节点——数据没错，但视角容易误解。

改动：

- 只要有至少 1 条链，`chainGraph` 就把**全库论文**都作为 paper 节点返回；
- 有链的论文 `chained:true, chains:N`；没链的 `chained:false, unchained:true, chains:0`；
- 未建链论文：暗紫底 + 灰虚线边框 + 透明度 0.65，排在画布下方 6 列网格；
- 统计条增加「未建链 N」；图例增加「未建链」；
- 点未建链论文：详情显示「还没有证据链」+「打开论文建链」；
- 没有链时顶部显示提示条；空库仍走空态。

验证：真实库 5 条链（全部 p-815）→ 图里 4 个论文节点（1 个 chained + 3 个 unchained），
`stats.papers=4 / chainedPapers=1 / unchainedPapers=3`；`npm test` **90 项全过**。
