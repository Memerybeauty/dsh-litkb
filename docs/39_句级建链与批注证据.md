# 句级建链与批注证据（v0.8）

| 项 | 内容 |
|---|---|
| 状态 | 已实施（v0.8.0） |
| 目标 | 从原文一句话建链；AI 链可编辑、证据可改；批注可转为链证据 |
| 涉及 | ParsePanel 选区、ChainDialog、AutoChainPanel、card.annotations |

## 1. 从一句话建链

原文解析里选中一句话后，浮动按钮：

```text
[追问] [建链] [评论]
```

点「建链」：

1. 先调用 `POST /card/evidence`，把选中句落成一条 `kind: selection` 的原文证据（q-id）；
2. 带着这条证据打开链编辑器，选中句是**证据节点**，不是论点；
3. 编辑器自动按已选证据提一个论点（可改），用户可增删证据、改关系后保存；
4. 同句同页重复建链复用同一条证据。

选区携带 `page / blockId / quote`，无 q-id 也能建链；q-id 由服务端按 quote/page/block 生成。

## 2. AI 自动链可编辑

- 自动建链审核面板：每条草稿的「编辑」直接打开 ChainDialog；
- 研究工作台证据链：链详情「完整编辑」；
- 编辑器内可：改论点、改关系、移除节点、从本论文/全库补证据、批量关系。

## 3. 批注转为链证据

在原文选区点「评论」：

- 写入 `card.annotations`，带 `quote / page / block` 锚点；
- 同时生成一条 `kind: 'comment'` 的卡片证据（`q-xxxxxxxx`），`quote` 是原句，`comment` 是批注文本；
- 这条证据会出现在：
  - 卡片证据列表（标注「批注」）；
  - 链编辑器的「本论文证据」；
  - 检索语料。
- 加入链后与普通证据一样可引用、可定位原文；批注作为节点 note 显示。

## 4. 数据结构

```json
"annotations": [{
  "id": "a-...", "at": "...", "text": "批注",
  "quote": "原句", "page": 3, "block": "b-...", "evidenceId": "q-..."
}]
```

```json
"evidence": [{
  "id": "q-...", "page": 3, "block": "b-...",
  "quote": "原句", "kind": "comment", "comment": "批注", "section": "批注"
}]
```

## 5. 边界

- 批注证据仍要求原句可定位；没有选区的纯文本批注只留在 annotations，不生成证据；
- 批注证据目前不参与“引文核对”的原文一致性检查；
- 同句多次评论会产生多条批注证据，暂不自动合并。
