## 1. 这一阶段做了什么

| # | 能力 | 说明 |
|---|---|---|
| 1 | 收文 | 拖拽 / 多选导入 PDF，sha256 去重 |
| 2 | 大类 | 知网 12 类单选（学术期刊 / 学位论文 / 图书 / 会议 / 报纸 / 年鉴 / 专利 / 标准 / 成果 / 学术辑刊 / 文库 / 法律法规） |
| 3 | 主题 | 扁平标签，关键词命中自动打标；可手动增删 |
| 4 | 标签管理 | 新增 / 删除（二次确认）/ 关键词编辑 / 重跑 |
| 5 | **导入反馈** | 每条导入都有结果：新增、重复、失败；toast + 批量结果面板 |
| 6 | **单条重试** | 失败项可只重传那一个文件 |
| 7 | 未归类 | 没有标签的论文进「未归类」，带角标 |

**没有**：置信度、用途/角色（已删）。

## 2. 导入的四种反馈

| 结果 | 提示 | 动作 |
|---|---|---|
| 新增 | 「已导入」+ 标题 | 打开 |
| 重复 | 「已在库中 · 未重复入库」+ 标题 | 打开已有 |
| 失败 | 「导入失败」+ 原因（加密/损坏/非 PDF/过大） | 查看后重试 |
| 批量 | 「成功 2 · 重复 1 · 失败 1」 | 查看逐条 |

判重口径：**只按文件 sha256**，不按 DOI（决策 B）。

## 3. 已验证（宿主 0.2.1-rc.5 + 无头 Chrome）

| 检查项 | 方法 | 结果 |
|---|---|---|
| 新增提示 | 上传 U-Net | 「已导入」+ 标题 + 打开 |
| 重复提示 | 再上传同一文件 | 「已在库中 · 未重复入库」，列表仍 1 篇 |
| 失败提示 | 上传截断的 PDF | 「导入失败：无法解析该 PDF」 |
| 批量汇总 | 同时传 REFUGE + 损坏文件 | 「成功 1 · 重复 0 · 失败 1」 |
| 结果面板 | 点「查看」 | 逐条状态，失败项有「重试」 |
| 错误码 | `not_pdf` / `parse_failed` / `too_large` | 文案对应正确 |

## 4. 你要做的 G2（5 条）

> 先 ⌘Q 退出 → 补一次注册（见 §5）→ 重新打开。

| # | 操作 | 通过标准 |
|---|---|---|
| 1 | 导入 1 篇 | 右下角「已导入」，点「打开」能进详情 |
| 2 | 同一篇再导入 | 「已在库中」，列表不增加 |
| 3 | 导入一个非 PDF 或损坏文件 | 「导入失败」+ 原因 |
| 4 | 一次选 3 个（含重复与失败） | 汇总「成功 x · 重复 y · 失败 z」，面板可重试 |
| 5 | 管理标签：新增一个→打标→删除 | 删除提示影响篇数，删后无残留 |
