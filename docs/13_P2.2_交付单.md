## 1. 这一版做了什么

| # | 能力 | 说明 |
|---|---|---|
| 1 | 版面块 | `blocks/<id>.json`：每页拆成标题/作者/摘要/段落/图注/页眉页脚/参考文献，带归一化 bbox |
| 2 | 稳定块 ID | `b-` + 8 位哈希（页码 + bbox + 文本）；重跑不变，已用 3 篇真实 PDF 验证 |
| 3 | 双栏处理 | 先按整宽行切区段，再在窄行区段找栏缝；左栏读完整再读右栏；栏缝在页间延续 |
| 4 | 页图 | `GET /api/litkb/page`：pdfjs + canvas 渲染 PNG，磁盘缓存，默认 120dpi |
| 5 | 解析稿面板 | 详情抽屉新增「解析稿」页签：左块、右页图；点块高亮原文，点原文滚到块 |
| 6 | 证据回链 | 卡片里的 `^q-` 引文自动匹配到 `b-` 版面块，返回 `block` 字段 |
| 7 | 导出 | `GET /api/litkb/blocks.md`：带 `<!-- b:xxxx p:N -->` 块锚点的 Markdown |
| 8 | PaddleOCR | 官方 API 异步任务：提交 → 轮询 → 下载 JSONL → 规范化；6 页约 26 秒 |
| 9 | 解析任务 | `POST /blocks/build` 返回 202 + job；前端轮询 `/blocks`，支持长任务 |
| 10 | 令牌配置 | 解析稿面板可直接粘贴 token；只存本地 `settings.json`，接口不回传 |
| 11 | 降级 | PaddleOCR 失败自动回 pdf.js 并显式警告；页眉页脚默认隐藏 |

**没有**：中英对照（P2.3）、内嵌 PDF 文本层划线、表格结构化。

## 3. 你要做的初验（3 条）

> 令牌已写入 `~/Documents/文献库/settings.json`（权限 600），重启后直接可用。
> ⌘Q 退出 → 重新打开（link 安装，无需重装）。

| # | 操作 | 通过标准 |
|---|---|---|
| 1 | 打开一篇 →「解析稿」→「构建解析稿」 | 1–3 秒出现左侧块列表 + 右侧页图 |
| 2 | 点左侧任意一块 | 右侧滚到对应页，并高亮该块的矩形区域 |
| 3 | 点右侧页图上的任意高亮框 | 左侧滚到对应段落并高亮 |

可选：点「导出 MD」，应下载带 `<!-- b:… -->` 锚点的解析稿；在 Obsidian 里能正常阅读。

## 4. PaddleOCR 已接入的接口

| 项 | 值 |
|---|---|
| 服务 | `https://paddleocr.aistudio-app.com` |
| 提交 | `POST /api/v2/ocr/jobs`，multipart：`model` / `optionalPayload` / `file` |
| 鉴权 | `Authorization: Bearer <AI Studio Access Token>` |
| 轮询 | `GET /api/v2/ocr/jobs/<jobId>`，`state: pending/running/done/failed` |
| 结果 | `resultUrl.jsonUrl` → JSONL；`result.layoutParsingResults[]` 逐页 |
| 块字段 | `prunedResult.parsing_res_list[]`：`block_label` / `block_content` / `block_bbox` / `block_order` |
| 坐标 | 像素坐标，`prunedResult.width/height` 归一化到 0–1 |
| 模型 | `PaddleOCR-VL-1.6`（可在设置里改） |

角色映射：`doc_title→title`、`paragraph_title→heading1`、`abstract→abstract`、`text→paragraph`、
`figure_title→caption`、`header→header`、`footnote→footer`、`table→table`、`formula→formula`、`reference→reference`。

失败不静默：PaddleOCR 报错时自动用 pdf.js 兜底，并在解析稿顶部显示「PaddleOCR 不可用，已用 pdf.js 兜底」+ 原因。

## 5. 已知限制

| 限制 | 说明 | 计划 |
|---|---|---|
| PaddleOCR 配额 / 网络 | 需要联网与 AI Studio 配额；超时会失败 | 自动回 pdf.js；面板可重试 |
| 表格 / 公式 | 已由 PaddleOCR 识别为整块，但结构化（单元格）仍未做 | P3 |
| 双栏 | PaddleOCR 按块给出顺序，不再依赖栏缝启发式 | 已改善 |
| 页数上限 | 解析 120 页、渲染不设上限 | 按需调整 |
| 页图缓存 | 120dpi 约 0.5–0.7MB/页，1GB LRU | 可在设置里降 dpi |
| 无 OCR | 扫描件仍无法切块 | PaddleOCR |
| 证据块回链 | 只在读卡片时补，不写回卡片 JSON | P2.3 落盘 |
| 解析稿纠错 | 不支持手工改块 | v1.1 再评估 |
| 中英对照 | 未开始 | P2.3 |

## 7. 补丁（2026-11-05，v0.3.3）

**问题**：七段卡里点 `p.N` 不跳转，「打开原文」也打不开。

**原因**：DSH Web GUI 的 WebView 拦截/不呈现 `target="_blank"` 的 PDF 新标签页；服务端 `/api/litkb/pdf` 本身正常（curl 200 / 3.29MB 已验证）。

**修复**：改为**应用内页图查看器**（复用 `/api/litkb/page`），不再依赖新标签页：

- `p.N` → 打开查看器并定位到该页；有解析稿时高亮证据所在块；
- 「打开原文」→ 打开查看器第 1 页；
- 支持上一页 / 下一页 / 下载 PDF；
- 解析稿「导出 MD」改用 `download`，避免弹窗被拦截。
