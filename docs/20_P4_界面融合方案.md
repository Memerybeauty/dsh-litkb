# P4 界面融合与重构方案（提案 v0.1）

| 项 | 内容 |
|---|---|
| 日期 | 2026-11-05 |
| 状态 | **已确认（A/A/A/A）**；P4.0–P4.7 已实施 |
| 范围 | 把「弹窗式文献库」改成 DSH 原生主面板；重排整个工作区 |
| 依据 | 当前 v0.16.0 代码 + 实时 DSH Slot 检查（`sidebar.panellist` / `main` / `layout` / `settings.section`） |

---

## 0. 结论

现在的问题是**形态问题**，不是样式问题：

- 文献库挂在 `shell.overlay` 上，是一个盖住整个 DSH 的浮层；子页面又套了详情抽屉、PDF 全屏层、追问弹窗、待归一弹窗；
- 用户每读一篇论文，要在「列表 → 抽屉 → 卡片 → 证据 → PDF 浮层 → Esc 返回」之间来回跳；
- 浮层会挡住对话、挡住侧边栏，也不能像 DSH 自带页面那样被侧边栏选中、保持、切换。

**目标形态**：注册 DSH 原生 `main` 面板 + 侧边栏 `sidebar.panellist` 图标，文献库成为和 Conversation / Plugins / Schedules 并列的一页；
页面内部改成**固定三栏工作台**：左侧文献列表，中间阅读/图谱，右侧原文/证据/追问/信息。除删除确认外，不再有模态弹窗。

**技术路线已核对可行**，不需要改 DSH 宿主，不需要 iframe，不需要改 profile 配置；只改插件的客户端注册与页面组件。

## 1. 现状核对

### 1.1 当前实际注册的 UI

| 位置 | 当前实现 | 问题 |
|---|---|---|
| `sidebar.footer.action` | 「文献库」按钮，切换 `openState` | 是浮层开关，不是页面导航 |
| `shell.overlay` | `Workspace`，`position:fixed` 的 1120×760 窗口 | 盖住整个 DSH；Esc/点遮罩关闭；不能与对话并存 |
| `Detail` | 右侧 780px 抽屉，内含「详情 / 七段卡 / 解析稿」 | 卡片与解析稿互斥，看不到 PDF |
| `PdfViewer` | 全屏 `position:fixed` 浮层 | 打开 PDF 就离开卡片；关掉才能继续读 |
| `AskPanel` | 右下角弹窗 | 追问时盖住正文，无法边看边问 |
| `ConceptQueue` | 居中弹窗 | 合并概念时看不到图 |
| `TagManager` | 抽屉 | 标签管理是独立浮层 |
| `GlossaryEditor` | 解析稿内联块 | 已不是弹窗，但位置局促 |
| `ResultsPanel` / `Toast` | 浮层内右下角 | 批量导入结果会遮住内容 |

### 1.2 用户路径对比

现在：

```
侧边栏「文献库」→ 浮层 → 点论文 → 抽屉 → 七段卡 → 点 p.N → PDF 全屏 → Esc → 抽屉 → 划词 → 追问弹窗
```

重构后：

```
侧边栏「文献库」图标 → 主面板 → 点论文 → 中栏读卡片，右栏一直是原文
  → 点 p.N：右栏翻页 + 高亮，不离开卡片
  → 划词：右栏切「追问」，答案与页码同屏
  → 切图谱：左栏变过滤，中间画布，右栏节点/边详情
```

## 3. DSH 原生接入方式（已用实时检查核对）

### 3.1 两个注册点

| 注册点 | 用途 | 关键参数 |
|---|---|---|
| `sidebar.panellist` | 侧边栏的全局面板图标 | `id: 'dsh-litkb'`、`order`、`label: () => '文献库'`；组件收到 `{ size, active }` |
| `main` | 中央主面板 | keyed slot，`key: 'dsh-litkb'`；与 `sidebar.panellist` 的 id 对应，侧边栏点击时自动选中 |

DSH 的 slot 目录明确写着：

- `sidebar.panellist`：**每个 list id 对应一个 main panel**，侧边栏负责按钮与选中；
- `main`：**Central panel selected by sidebar entry id**；除 `conversation` 外不绑定 Session；
- `ctx.layout.selectPanel('dsh-litkb')`：选中该面板；key 未注册时保持当前选择；
- `settings.section`：可另注册一个「文献库」设置页。

### 3.2 代码形态（示意，不是最终实现）

```js
function apply(ctx) {
  // 1) 侧边栏全局图标
  ctx.slots.inject('sidebar.panellist', () => ctx.slots.register({
    name: 'sidebar.panellist',
    id: 'dsh-litkb',
    order: 20,
    label: () => '文献库',
  }, LitkbIcon), 'dsh-litkb: panel icon')

  // 2) 原生中央面板
  ctx.slots.inject('main', () => ctx.slots.register({
    name: 'main',
    key: 'dsh-litkb',
  }, LibraryPage), 'dsh-litkb: main panel')

  // 3) 可选：原生设置页
  ctx.slots.inject('settings.section', () => ctx.slots.register({
    name: 'settings.section',
    id: 'dsh-litkb',
    order: 30,
    label: () => '文献库',
  }, LitkbSettings), 'dsh-litkb: settings')

  // 4) 删除旧注册
  // - shell.overlay
  // - sidebar.footer.action
}
```

注意：

- **不要 iframe**：主面板必须是 React 组件，才能继承 DSH 主题、语言、焦点与快捷键；
- **不要 `document.body`**：所有 UI 在 slot 内；
- **不要复用 `conversation` key**：那是会话 shell 的保留 key；
- 主面板是 root scope，不绑定 Session；切换会话不会丢文献库；
- `main` 与 `sidebar.panellist` 的 key 必须一致，否则点了图标会空白。

### 3.3 入口取舍

| 方案 | 说明 | 推荐 |
|---|---|---|
| A. 只保留 `sidebar.panellist` 图标 | 与 Plugins / Schedules 一致；最像 DSH 原生 | ✅ 推荐 |
| B. 图标 + 底部「文献库」按钮 | 多一个入口，但重复 | 过渡期可用 |
| C. 只保留底部按钮，点击后 `selectPanel` | 入口不显眼，且与原生面板列表不一致 | 不推荐 |

推荐 **A**；迁移期先保留 B，验收后删掉底部按钮，避免两个入口。

## 4. 页面内部重构

### 4.1 外壳

- 顶部 56px：面板标题、库路径、全局搜索、导入、刷新；
- 第二行 40px：模式切换「总览 / 论文库 / 图谱 / 未归类」；
- 主体：`grid-template-columns: 300px minmax(0,1fr) 380px;`
- 底部 28px 状态条：库统计、模型状态、最近保存、任务进度；
- 全部使用 `--dsw-alias-*` token；不画自己的窗口边框、圆角卡片、阴影；
- 面板本身 `height:100%; min-height:0; display:flex; flex-direction:column;`，内部各栏独立滚动。

### 4.2 左栏：论文列表

- 顶部：状态筛选（全部/待读/精读/已引用/弃读/未归类），计数；
- 搜索：先做**本地过滤**（标题/作者/标签），P4 后期接全文检索；
- 列表行：标题（1 行省略）、年份·类型、标签 chips、状态点、卡片/证据角标；
- 选中行用 DSH 的 fill token 高亮；
- 底部：管理标签、库统计；
- 支持 200 篇滚动；不做虚拟列表也可以先上，超过 500 篇再虚拟化。

### 4.3 中栏：阅读区

- 论文头：标题、作者/年份/期刊、状态 pill、操作（编辑/重生成/导出/打开 PDF）；
- 两个视图：
  - **七段卡**：七段正文 + 行内证据；顶部锚点 chips 1–7 跳段；
  - **解析稿**：块文本 + 「原文/对照/译文」切换 + 术语表入口；
- 选中文字 → 出现小「追问」浮钮 → 点击把选区送右栏「追问」；
- 点证据 `p.N` → 右栏「原文」翻页并高亮，不离开中栏；
- 卡片编辑、批注、版本历史改为行内展开/右栏「信息」，不再开抽屉。

### 4.4 右栏：上下文

四个 tab：

| Tab | 内容 | 默认 |
|---|---|---|
| 原文 | 单页页图 + 上/下页 + 页码输入 + 块高亮；可展开 | ✅ 论文阅读默认 |
| 证据 | 当前论文证据列表，按段落分组；点一条同步原文 | |
| 追问 | 选区引用 + 问题输入 + 回答（`[p.N]` 可点）+ 存批注 | |
| 信息 | 元数据、标签、质量分、卡片状态、版本历史 | |

规则：

- 右栏只渲染**当前页 ±1**，不再一次渲染 74 页页图（当前 `PdfViewer` 会渲染全部页，重）；
- 右栏可折叠（按钮/快捷键），折叠后中栏变宽；
- 无选中论文时显示「选择一篇论文」；
- 追问是**线程**，不是一次性弹窗；同一篇的追问保留在右栏，切换论文时清空或按论文缓存。

### 4.5 图谱

- 左栏：主题、年份、类型、搜索、图例；
- 中栏：画布；顶部「构建/强制重建/刷新/可比组」；底部统计；
- 右栏：节点/边详情；「待归一」折叠区，合并/批准后原地刷新；
- 可比组：中栏切换为表格，左栏保留过滤，右栏可放指标说明；
- 画布用 `ResizeObserver` 重新布局；300 节点 ≤2s；
- 不做拖拽/缩放也可以先交付，但右栏详情必须常驻。

### 4.6 未归类

- 左栏：未归类列表；
- 中栏：选中论文的标题/摘要片段 + 「加标签」操作；
- 右栏：标签管理（新建/编辑关键词/删除影响提示），不再开抽屉。

## 5. 弹窗迁移表

| 现在 | 改成 | 行为 |
|---|---|---|
| `Workspace` overlay | `main` 面板 | 侧边栏选中，不再遮罩 |
| `Detail` 抽屉 | 中栏 + 右栏「信息」 | 详情不再是独立层 |
| `PdfViewer` 全屏 | 右栏「原文」 | 翻页/高亮不离开卡片；可展开 |
| `AskPanel` 弹窗 | 右栏「追问」 | 选区 → 引用卡 → 回答 |
| `TagManager` 抽屉 | 左栏底部/未归类右栏 | 标签管理原地完成 |
| `GlossaryEditor` 内联 | 右栏「对照」子面板 | 翻译时同屏 |
| `ConceptQueue` 弹窗 | 图谱右栏「待归一」 | 合并时图仍在 |
| `ResultsPanel` / `Toast` | 右栏「导入结果」/底部状态 | 批量导入不挡内容 |
| 版本历史（已内联） | 右栏「信息」 | 保留回滚 |
| `window.confirm` 删除 | 行内二次确认条 | 不用浏览器弹窗 |

**例外**：真正不可逆的删除仍可保留一次确认，但用页面内确认条，不用模态。

## 6. 交互与状态

- **默认选中**：上次打开的论文（`localStorage` 记 `lastPaperId`）；没有就显示总览。
- **模式记忆**：上次模式（总览/论文库/图谱/未归类）持久化。
- **右栏 tab 记忆**：论文阅读默认「原文」；用户切到「追问」后，本次会话保持。
- **切换面板**：从文献库切到对话再切回，保留论文与模式；不重新拉全库。
- **键盘**：
  - `Esc`：关闭右栏展开/取消选区，不关闭面板；
  - `Cmd/Ctrl+Enter`：提交追问；
  - `j/k` 或上下键：列表移动（可选）；
  - 所有图标按钮有 `aria-label`。
- **响应式**：
  - ≥1280：300 / flex / 380；
  - 1024–1280：280 / flex / 320；
  - <1024：右栏折叠为 tab 抽屉（页面内，不是 shell overlay）。
- **拖拽导入**：整个面板是 drop target，拖入时显示边框提示；不再依赖 overlay。
- **加载/失败**：栏内 skeleton/错误条；不整页白屏；模型不可用时按钮禁用并说明。

## 7. 视觉规范

- 颜色只用 `--dsw-alias-*`：`bg-base`、`label-primary/secondary/tertiary`、`border-l1/l2`、`fill-l1`、`state-accent-primary`；
- 字体：面板标题 14px/600，正文 12.5–13px，元信息 11px；
- 行高：列表行 32–36px；卡片段间距 16–20px；
- 圆角：6–8px；不用大圆角卡片堆叠；
- 分隔：1px `border-l1`；不用阴影做层级；
- 按钮：主按钮实心 accent，次按钮 ghost；与 DSH 现有按钮一致；
- 空态：居中图标 + 一句说明 + 一个主操作；
- 图标：线性书本/文献图标，`currentColor`，`size` 由侧边栏传入；选中态用 accent。

## 10. 风险与取舍

| 风险 | 影响 | 对策 |
