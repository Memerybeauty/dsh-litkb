# 阅读状态自动标记（v0.15.0）

> 七段卡 = 略读，精读 = 精读；但状态不是强绑定，用户手动切换后以用户为准。

| 项 | 内容 |
|---|---|
| 版本 | v0.15.0 |
| 自动规则 | 七段卡成功 → 略读；精读成功 → 精读 |
| 不降级 | 已是精读，重新生成七段卡不会退回略读 |
| 手动优先 | 手动切换后 `statusSource=manual`，自动规则停止覆盖 |
| 迁移 | 旧库按已有卡片/精读补一次状态 |
| 路由 | 不变（86 条） |

---

## 1. 规则

```text
导入            待读
  ↓ 七段卡生成成功
略读
  ↓ 精读生成成功
精读
```

- 自动只升不降：`待读 < 略读 < 精读`；
- `已引用 / 弃读` 不参与自动标记；
- 手动切换任意状态后，后续自动标记不再覆盖；
- 状态仍可在论文详情 → 七段卡页签的下拉里随时改。

## 2. 实现

| 文件 | 作用 |
|---|---|
| `lib/paper-status.js` | `applyAutoStatus` / `migrateAutoStatuses` / `inferredStatus` |
| `src/server/20-jobs.js` | 卡片任务成功 → 略读；精读任务成功 → 精读；入库完成兜底 |
| `src/server/30-edit-helpers.js` | 手动状态 → `statusSource=manual` |
| `src/server/10-import-helpers.js` | 编辑论文时手动改状态同样标 manual |
| `src/server/40-apply-routes-library.js` | 启动时迁移旧库 |
| `src/client/20-reading.js` | 状态下拉标题与说明文案 |

## 3. 旧库迁移

启动时对没有 `statusSource` 的记录：

| 当前 | 产物 | 迁移后 |
|---|---|---|
| 待读 | 有精读 | 精读（auto） |
| 待读 | 有七段卡 | 略读（auto） |
| 已引用 / 弃读 | — | 保持，标 manual |
| 略读 / 精读 | — | 保持，标 auto |
| 待读 | 无 | 保持，标 auto |

迁移幂等；当前库 5 篇「待读但有精读」会在重启时变成精读。

## 4. 边界

- 自动标记只改论文索引状态，不改卡片内容；
- 卡片 Markdown 头部的旧状态不会即时重写，以列表/详情状态为准；
- 不做“恢复自动状态”按钮：手动切换后如需恢复自动，可重新生成卡片/精读，或在后续版本补。
- 状态不是权限或流程门禁：任何状态都能继续生成、建链、写作。
