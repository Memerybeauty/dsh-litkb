## 1. 这一版做了什么

| # | 能力 | 说明 |
|---|---|---|
| 1 | 段编辑 | 七段正文可改；保存写回 `card.json` + `md`；旧版自动备份 |
| 2 | 批注 | 「我的批注」追加，带日期与 `a-` ID，不覆盖正文 |
| 3 | 状态 | 七段卡顶部自由切换（5 个状态）；不校验顺序；弃读原因可选 |
| 4 | 逐段重生成 | 只让模型重写某一段，只替换该段与其证据，其他段不动 |
| 5 | 版本回滚 | `cards/.versions/` 保留最近 20 份；可恢复任意一版 |
| 6 | 编辑保护 | 空正文、超 2000 字、未知段落均拒绝；每次写入前备份 |

**没有**：草稿态（保存即生效）、协同编辑、批注线程/回复、PDF 批注。

---

## 2. 接口

| 接口 | 请求 | 行为 |
|---|---|---|
| `POST /card/section` | `{id, key, text}` | 校验 key/长度；备份；写回 JSON + MD |
| `POST /card/annotate` | `{id, text}` | 追加批注 `{id, at, text}` |
| `POST /card/status` | `{id, to, reason?}` | 迁移表校验；弃读必填原因；写 statusHistory |
| `POST /card/regenerate` | `{id, key?}` | 省略 key = 整卡；有 key = 单段（202 + job） |
| `GET /card/versions` | `?id=` | 版本列表（新→旧） |
| `POST /card/restore` | `{id, version?}` | 恢复指定/最新一版 |

状态：`待读 / 略读 / 精读 / 已引用 / 弃读` 自由切换，不做迁移校验；详情页不再放状态控件，状态在七段卡顶部。

## 4. 你要做的初验（5 条）

> ⌘Q 退出 → 重新打开（版本 **0.4.2**）。

| # | 操作 | 通过标准 |
|---|---|---|
| 1 | 打开七段卡 → 某段「编辑」→ 改文字 → 保存 | 卡片立即更新；重开/刷新后仍是新文字 |
| 2 | 「我的批注」写一条 → 添加 | 列表出现日期 + 内容；正文不变 |
| 3 | 七段卡顶部改状态：任意方向 | 都能保存；不需要填原因 |
| 4 | 某段「重生成」 | 只该段变化；其他六段不动；旧版可回滚 |
| 5 | 「历史版本」→ 恢复较早一版 | 卡片回到该版本；时间显示为本机时间 |

## 5. 已知限制

| 限制 | 说明 | 计划 |
|---|---|---|
| 无草稿 | 保存即写回；有版本备份但无「暂存」 | 设计如此 |
| 单段重生成仍读全文 | 上下文更完整，但 token 成本与整卡接近 | 可优化为只送相关章节 |
| 批注纯文本 | 不支持 @、回复、折叠 | P3 |
| 状态随意 | 不做顺序校验，状态可信度由用户负责 | statusHistory 可追溯 |
| 版本 20 份 | 超出自动删最旧 | 可配置 |
| 真实模型 | 单段重生成未跑真实模型 | 本次初验 |
