## 2. 详细清单

### M1 库管理 🟡

- ✅ 默认库 `~/Documents/文献库`，可用 `LITKB_LIBRARY` 覆盖；
- ✅ 首次读取自动建 `papers/ cards/ blocks/ translations/ concepts/ exports/ cache/ text/` 与 `index.jsonl`、`tags.json`；
- ✅ `GET /api/litkb/health`、`GET /api/litkb/diag`（版本、模型、任务、待归一数）；
- 🟡 没有设置页切换库、没有索引重建按钮、没有整库备份；
- 🟡 索引是缓存，坏了目前只能靠重新导入/手工修。

### M2 收文 🟡

- ✅ 窗口拖拽多 PDF、系统文件选择器多选；
- ✅ 顺序批量导入，显示 `正在解析 n/N`；
- ✅ sha256 判重：重复不新增，提示「已在库中」并可打开已有记录；
- ✅ 失败分类：非 PDF、超 80MB、加密、解析失败、网络；
- ✅ 单条 toast + 批量结果面板（新增/重复/失败、原因、单条重试）；
- ✅ 低质量（quality < 0.4）仍入库，但提示「解析质量偏低」；
- ⏸ 没有 DOI / arXiv 链接导入；
- ⏸ 没有目录扫描、没有导入队列取消；
- ⏸ 导入是同步 HTTP 上传，不是持久任务队列。

### M3 识别补全 🟡

- ✅ 从 PDF 文本抽标题、作者、年份、期刊/会议、DOI（正则）；
- ✅ 按 12 类 + 标签关键词自动归类；
- ✅ 详情里可手改标题/年份/大类/标签，保存即生效；
- 🟡 没有 Crossref / OpenAlex 元数据补全；
- 🟡 没有 DOI 级判重（明确只按 sha256，同 DOI 不同文件算两篇）；
- 🟡 citekey 直接用 `p-xxxxxxxx`，不能自定义。

### M4 大类与标签 ✅

- ✅ 12 个知网大类，单选；
- ✅ 扁平标签，多对多，可增删；
- ✅ 每个标签可配关键词，导入时自动命中（标题 ×3、正文 ×1，最多 5 个）；
- ✅ 「未归类」作为论文库筛选 chip，不再单独页签；
- ✅ 详情页勾选/取消标签，一键新建标签并打上；
- ✅ 「管理标签」：新增、删除（提示影响篇数）、编辑关键词、按当前标签全量重跑；
- 🟡 没有标签合并、没有标签颜色/层级（按设计就是扁平）。

### M5 解析 ✅

- ✅ 分页文本 + 质量评分（字符数、空页、乱码）；
- ✅ 章节切分（Abstract/Introduction/Method/Results/Conclusion/References 等）；
- ✅ 块级解析：PaddleOCR-VL-1.6 官方 API 为主，pdf.js 兜底；
- ✅ 块带 `page / bbox(0–1) / role / section / order / text`，块 ID 稳定；
- ✅ 解析稿：`blocks/<id>.json` 真源，可导出带 `<!-- b:xxxx p:N -->` 锚点的 Markdown；
- ✅ 页图：服务端 PNG（pdf.js + canvas），磁盘缓存；
- ✅ 解析稿 ↔ 页图双向定位，点块高亮 bbox，点页图块回滚解析稿；
- 🟡 表格/公式只整块识别，不拆单元格；
- 🟡 图表号不自动识别；
- 🟡 扫描件必须配 PaddleOCR token，纯 pdf.js 不可用；
- 🟡 页数上限：分页文本 80 页、pdf.js 版面 120 页（代码常量，未做 UI 提示；PaddleOCR 路径按 API 任务页数）。

### M6 七段卡 ✅

- ✅ 七段：一句话 / 问题与动机 / 方法 / 数据与实验 / 结果 / 局限 / 与我的课题；
- ✅ 一次模型调用生成整卡，引文回贴原文，定位失败丢弃并记 warning；
- ✅ 卡片状态 `ready / partial`，缺段/缺证据显式提示；
- ✅ 逐段编辑，保存写回 `card.json` + `card.md`，旧版进 `cards/.versions/`；
- ✅ 逐段重生成（只换该段与其证据）与整卡重生成；
- ✅ 历史版本列表、恢复上一版/指定版本（保留最近 20 份）；
- ✅ 状态自由切换：待读/略读/精读/已引用/弃读，`statusHistory` 记录；
- ✅ 追加批注，带日期，不覆盖正文；
- 🟡 状态切换 UI 没有「弃读原因」输入框（API 支持 reason，UI 未暴露）；
- 🟡 不能直接编辑引文/证据，只能重生成该段。

### M7 证据链 ✅

- ✅ 引文块 ID `^q-xxxxxxxx`（内容哈希，重跑稳定）；
- ✅ 证据带页码 + 版面块 ID + bbox + 前后上下文；
- ✅ 点 `p.N` 打开页图并高亮对应块；
- ✅ 卡片读取时自动修复失效/缺失块（按页 + 引文回贴）；
- ✅ 块断链提示「块已失效，按页定位」，不静默；
- ✅ 上下文展开（before/after）；
- ✅ 证据导出 JSON / CSV；反链按钮：被哪些卡片/草稿引用（文件、行号、行文本）；
- ✅ 反链 UI 已开放，无结果显式「未被引用」；
- 🟡 图表号仍不识别。

### M8 图谱 ✅

- ✅ 受控词表 `concepts/concepts.json`：方法 / 数据集 / 指标；
- ✅ 归一化 + 别名：大小写/空格/连字符/全半角归一；改名不换 ID，旧名进别名；
- ✅ 待归一并列：相似但没把握的概念进 `pending`，不画进图；
- ✅ 人工处理：合并到已有、改名、加别名、批准为新概念；合并后边自动重指并重建；
- ✅ 四类边：`uses / improves_on / evaluates_on / reports`；
- ✅ 证据白名单：每条边必须引用卡内已有 evidence_id，页码/块/引文从证据复制，不接受模型瞎编；
- ✅ `reports` 必须带数字，尽量带数据集；这是可比组唯一来源；
- ✅ 增量构建（有缓存跳过）与强制重建；串行任务 + 进度 + 丢弃计数 + 单篇失败不拖垮全局；
- ✅ 无卡片论文跳过并在摘要里显示「无卡 N 篇」；
- ✅ 图谱页：Canvas 力导向、主题/年份/方法·数据集·指标/名称搜索过滤；
- ✅ 点节点看邻居，点边看类型/论文/引文/页码/置信度；`p.N` 跳页并高亮（无解析稿显示「仅到页」）；
- ✅ 可比组：按「数据集 + 指标」分组，同篇取最新，数值降序，表格含论文/数值/年份/证据；
- ✅ 真实库：47 条边，逐条审计 47/47 合法；58 个概念，2 个待归一；
- ✅ 支持 Mermaid / Obsidian Canvas 导出；
- 🟡 图交互不支持拖拽节点/缩放画布；
- 🟡 单篇重建只有 API 参数，UI 只有增量/全量；
- 🟡 概念准确率没有人工金标准，当前靠 pending 队列兜底。

### M9 检索 ✅

- ✅ `lib/search.js`：证据 + 链的 BM25；中文 Intl.Segmenter + 二元组，英文按词；
- ✅ `GET/POST /api/litkb/search`、`POST /api/litkb/search/answer`；
- ✅ 链优先答案：有模型走 `chain-answer.v1`，无模型抽取式；q-id 白名单 + 逐句引用检查；
- ✅ 检索页：链答案/只看证据、引用回原文、命中链、trace；
- ✅ 30 篇/300 证据实测 18–21ms；
- 🟡 LLM 重排未做（可选）；向量检索不做（本地优先）。


### M10 精读 ✅

- ✅ 右栏：原文连续滚动/页码/80–250% 缩放/块高亮；证据列表；信息；追问内联；
- ✅ 解析稿视图：块文本、角色、页码、原文/对照/译文；
- ✅ 划词追问：解析稿块或七段卡正文选中 → 浮动「追问」；
- ✅ 追问材料：选中段 + 同页上下文 + 七段卡 + 证据；问题点名另一篇时补它的卡片（最多 2 篇）；
- ✅ 回答必须带 `[p.N]`；越界页码标红、不计引用；无有效引用警告；没依据要求回答「原文没有足够依据」；
- ✅ 引用页码可点跳页；回答可一键存为「我的批注」；
- 🟡 追问是同步请求（单次 30–90 秒），不是任务；
- 🟡 原文是 PNG 页图连续滚动，**不支持文本层划词/缩放**；选区来自解析稿/卡片；
- 🟡 没有三栏主屏（仍是详情抽屉 + 页图查看器）；
- 🟡 页图查看器没有缩放/旋转。

### M11 导出 🟡

- ✅ 单篇证据 JSON / CSV；
- ✅ BibTeX 单篇/整库；GB/T 7714-2015 单篇；卡片 Markdown；
- ✅ 图谱 Mermaid / Obsidian Canvas；
- ✅ 解析稿 Markdown（块锚点）；
- ✅ 原文 PDF 下载/打开；

- ⏸ 整库 Obsidian vault 导出；
- ⏸ 综述草稿导出、双语 Markdown 导出。

- ✅ PaddleOCR token 与模型名保存在 `<库>/settings.json`（0600，不回传 token）；

- 🟡 没有「是否发送正文给模型」开关（实际生成/翻译/追问都会发送必要文本）。

## 8. 结论

主链路已打通：

**收文（PDF / DOI / arXiv / 链接）→ 归类/解析 → 七段卡/精读 → 证据链/自动草稿审核 → 横向对比/图谱 → 链检索答案 → 研究主题建链 → 写作/导出**

v0.4.0：132 项测试、76 条路由、12 个 Agent 工具；研究工作台把「研究主题 → 匹配论文 → 主题证据链 → 研究内容 → 提纲」串成一条可审核的链路。
当前仍是「可用的研究工作台」，还不是「规模化验证过的成品」：差在真实 30 篇人工质量评估、真实主题试用、LLM 重排/语义召回、文件夹监控/队列、整库导出、任务续跑与成本页。
