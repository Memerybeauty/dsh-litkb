## 1. 背景与问题

### 1.1 现状

目标用户是医学影像/计算机交叉方向的研究生，手里有 50–200 篇 PDF、一个 Obsidian 库、若干版开题报告。文献工作被切成四段互不相通的流程：

```
下载 PDF ──▶ 存进文件夹 ──▶ 读（读一半）──▶ 写的时候再翻一遍
   （乱）        （找不到）       （记不住）        （引不准）
```

### 1.2 四个具体问题

| # | 问题 | 现在的做法 | 代价 |
|---|---|---|---|
| 1 | 存了找不到 | 文件夹 + 脑子 | 重复下载、重复阅读 |
| 2 | 读了连不起来 | Excel 记要点 | 写综述时还得重读 |
| 3 | 写了证不实 | 凭记忆写，回头核 | 改一版核一遍 |
| 4 | 新文献怕漏 | 手动刷 arXiv | 焦虑但不高效 |

### 1.3 为什么现在能做

DeepSeek Harness 的插件机制已成熟：`dsh plugin add` 可安装第三方插件，插件能进侧边栏、能开工作区、能给 Agent 加工具（机器上的 `dsh-worktable` 已验证）。这意味着不必让用户装 Python、配服务，**装一个包就能用**。

## 2. 产品定义

> **一句话**：论文进来，自动归位、拆成证据、连成图谱。
> **形态**：DeepSeek Harness 插件，侧边栏一个「文献库」，数据是本地文件夹（Markdown + PDF），Obsidian 可随时打开。

**它是什么**：

- 一个**自动整理**的文献库：三轴归类，不用手工建文件夹；
- 一个**结构化阅读器**：七段式卡片 + 内嵌 PDF + 划线追问；
- 一个**可对照的解析器**：全文拆成块（标题/段落/图注/表注），每块带页码与版面坐标；点解析稿能高亮原文，点原文能回到解析稿；
- 一个**中英对照阅读器**：英文论文一键出中文，按块对照，术语与数字保持原样，随时切回原文；
- 一个**证据系统**：每条结论挂到原文页码与版面块，可反查；
- 一个**知识图谱**：方法、数据集、指标之间的关系，边有出处；
- 一个**可维护的分类体系**：类目与关键词由你定，改完即生效。

**它不是什么**：

- 不是 PDF 阅读器（阅读只是它的一个面板）；
- 不是通用问答（只回答"库里的文献怎么说"）；
- 不是 Zotero 替代（不做文献格式管理、不做引文插入 Word）；
- 不是翻译软件（译文是阅读辅助，机翻标记常驻，不做出版级精校）；
- 不是一键写综述（写作是副产品，证据才是产品）。

### 2.1 两个轴：大类 + 主题

| 轴 | 取值 | 规则 |
|---|---|---|
| **大类** | 学术期刊 / 学位论文 / 图书 / 会议 / 报纸 / 年鉴 / 专利 / 标准 / 成果 / 学术辑刊 / 文库 / 法律法规 | 单选；沿用知网文献类型 |
| **主题** | 自建扁平标签 | 多选；可增删，参考微信标签体系 |

> **为什么删掉"用途/角色"**：验收时它只有标签、没有动作，属于解释不清的维度。v1.2 删除；等 P3 有「可比组 / 方法谱系」时，以视图形式从已有数据推导，而不是让用户先打标。

### 2.2 标签体系（参考微信）

- 标签**扁平**，不建树；标签名即标识；
- 一篇论文可打多个标签，一个标签可挂多篇；
- 标签可随时**新增、删除**；删除标签 = 从所有论文上摘掉（二次确认并提示影响篇数）；
- 每个标签可选配关键词，用于新论文自动打标；不配就纯手动；
- **没有置信度**：自动打标只有"命中 / 未命中"，未命中的进「未归类」；
- 打标结果随时可改，改完立即生效。

## 6. 核心流程

### 6.1 主流程

```
收文 → 识别补全 → 三轴归类 → 解析（分页 → 块）→ 七段卡 → 证据锚定 → 图谱 → 消费（查/看/读/写）
```

### 6.2 三条关键路径

| 路径 | 触发 | 结束条件 |
|---|---|---|
| 入库 | 拖入 PDF | 卡片骨架生成、列表可见、状态"待读" |
| 精读 | 打开卡片 | 七段读完、证据可跳、状态"精读" |
| 取用 | 写一段 / 问一句 | 返回带页码的引用块，或草稿段落 |

---

### 6.3 导入的四种结果

| 结果 | 触发 | 提示 | 可做的动作 |
|---|---|---|---|
| **新增** | 入库成功 | 「已导入《标题》」 | 打开详情 |
| **精确重复** | 文件 sha256 已存在 | 「《标题》已在库中，未重复入库」 | 打开已有记录 |
| **失败** | 非 PDF、加密、损坏、过大、解析失败 | 「xxx.pdf 导入失败：加密 PDF，无法解析」 | 重试 / 查看原因 |

规则：

- **一条都不能静默**：每个文件都要有结果，成功也算一条；
- 批量导入结束弹**汇总**：`成功 2 · 重复 1 · 失败 1`，点开看逐条；
- 重复只按文件判：sha256 相同即跳过；**不做 DOI 级判重**（决策 B）；
- 失败带**稳定错误码**，前端只翻译人话，不猜原因。

### 6.4 对照阅读（P2.2 / P2.3）

```
打开论文
  → 左：PDF 页（服务端渲染）｜右：解析稿（块）
  → 点解析稿任一块：PDF 滚到该页并高亮 bbox
  → 点 PDF 任一块：解析稿滚到对应块
  → 需要中文：切「对照」，逐块显示译文；「译文」只看中文
  → 译文块标「机翻」，一键回到原文
```

规则：
- 块高亮误差不超过该块 bbox 的外接矩形；
- 解析失败的页退化为页级对照（只到页），并标「该页未切块」；
- 翻译失败只影响该块，原文照常显示。

### 6.5 卡片编辑、批注与状态（P2.5）

```
打开卡片
  → 改某段正文 → 保存（card.json + card.md，旧版备份）→ 重开仍在
  → 追加批注（带日期，不覆盖正文）
  → 改状态（按迁移表校验；弃读必须填原因）
  → 某段不满意 → 只重生成该段（不重跑全卡）→ 可回滚上一版
```

状态：

- 详情页不再放状态控件；状态在七段卡顶部切换；
- **自由切换**（待读 / 略读 / 精读 / 已引用 / 弃读），不做迁移校验；
- 弃读原因可选，填了才记录；状态与原因由用户自己负责。

### 6.6 中英对照（P2.3）

```
打开论文 → 选范围（摘要+结论 / 本章 / 整篇 / 单块）
  → 整篇先显示字符数与预估耗时，确认后提交任务
  → 任务队列逐批翻译，显示进度
  → 视图：原文 / 对照 / 译文
  → 失败块标红，可单块重译
  → 术语表在「标签与术语」管理页维护；改后相关块懒失效
```

规则：
- 逐块翻译，不合并块、不改块序；
- 数字、单位、数据集名、方法名、引用标记原样保留；术语按 glossary 强制；
- 译文不覆盖原文，机翻标记常驻；
- 单篇默认只译「摘要 + 结论」，整篇需显式确认。

### 6.7 证据链收尾（P2.6）

- 证据卡展开显示 `before / after` 上下文；
- 块 ID 失效时提示「块已失效，按页定位」，不静默；
- 反链：这条证据被库内哪些卡片/草稿引用（扫描 `cards/` 与 `exports/`）；
- 导出：JSON / CSV（论文、页码、引文、块 ID）；
- 图表号暂不自动识别，留 P3。

### 6.8 图谱构建（P3）

```
图谱页 → 点「构建图谱」
  → 逐篇读七段卡与证据（没有卡就跳过并说明）
  → 模型抽方法 / 数据集 / 指标 / 四类边
  → 概念归一：别名命中 → 批量判定 → 待归一队列
  → 校验：每条边必须引用卡里已有的证据；不合法直接丢弃并计数
  → 落盘 concepts/concepts.json + concepts/edges.jsonl
  → 图页出现节点与边，点边看引文与页码
```

规则：
- **边只从证据来**：模型只能引用输入里给出的 `q-xxxx`；引用不存在、页码对不上、报告值缺失的边一律丢弃；
- **概念不自由生长**：同类同名（归一化后）只保留一个；拿不准的进「待归一」，人工合并后才画；
- **增量**：已有分析且未强制的论文跳过，避免重复计费；强制重建只影响选中的论文；
- **报告值**：`reports` 边带 `metric + value + dataset`，数值必须是数字，这是可比组的唯一来源。

### 6.9 精读追问与可比组（P3）

```
解析稿 / 七段卡里划一句 → 点「追问」→ 输入问题
  → 只带本文材料（选中段 + 上下文 + 卡片 + 证据；问到别的论文时补它的卡片）
  → 回答里每个断言带 [p.N]，点页码跳到页图
  → 资料里没有的，回答「原文没有足够依据」，不猜
  → 可一键存为「我的批注」
```

可比组：

```
图谱页 → 可比组 → 选「数据集 + 指标」
  → 表格：论文 / 数值 / 年份 / 证据
  → 点证据跳到原文页
```

规则：
- 追问上下文默认只含**本文**；问题里点名另一篇（标题或 citekey）才把它的卡片加入材料，并在回答里标明来源；
- 页码校验：`[p.N]` 的 N 必须在本次材料页码集合内；越界页码标红提示，不计入引用；
- 回答没有页码时显式警告「回答未标注页码」；
- 可比组只聚合 `reports` 边；同篇同指标取最新值，按数值排序并保留年份。

### 6.10 导出与反链（P4.6）

```
论文详情 / 右栏证据 → 导出 BibTeX / GB/T / 卡片 MD
图谱 → 导出 Mermaid / Canvas
整库 → 导出全部 BibTeX
证据 → 反链：被哪些卡片/草稿引用
```

规则：

- BibTeX 字段来自 `index.jsonl` + 卡片；缺字段不编造，空字段省略；
- GB/T 7714-2015 单篇导出；类型映射 J/D/M/C/S/P/N 等，作者/题名/年份/刊名缺失时留空或省略；
- 卡片 Markdown 直接导出 `cards/<id>.md`（含 frontmatter、七段、证据、批注）；
- Mermaid/Canvas 从 `concepts/edges.jsonl` 生成，只含 active 概念；
- 反链只扫 `cards/*.md` 与 `exports/*.md`；排除引文自己的卡片；结果给出文件、行号、该行文本；
- 没有反链时明确显示「未被引用」，不隐藏入口。

### 6.11 写作（P4.7）

```
写作页 → 新建文稿 → 写标题/正文
  → 右栏引用库搜索证据 → 插入引用
  → 证据旁「引用」→ 自动插到当前文稿
  → 检查未引用断言 / 生成参考文献
  → 导出带参考文献的 Markdown
```

规则：

- 文稿是纯 Markdown，Obsidian 可直接打开；
- 引用固定为 `[[p-xxx#^q-xxxx|作者 年, p.N]]`，便于反链与回原文；
- 自动保存：输入 1.5 秒后保存，显示保存状态；
- 引用库覆盖全库证据，可搜引文/标题；插入到光标处；
- 参考文献只从文稿引用生成，去重、按出现顺序；缺失证据显式列出；
- AI 扩写只能基于选中的 1 条或多条证据；生成段落必须带对应引用，缺引用/编造即标警告；
- 反链扫描 `drafts/`，证据旁能看到被哪篇文稿引用。

---

### 6.12 精读（P4.9）

```
论文 → 精读 → 生成（后台任务）
  → 11 个板块的结构化 Markdown 说明
  → 点 [p.N] 回原文
```

11 个板块，顺序固定：

1. 文献基本资料
2. 研究内容
3. 方法
4. 样本量
5. 研究时间
6. 图表解析
7. 结论
8. 创新点
9. 局限性
10. 可复刻性
11. 核心要点

规则：

- **不是抄原文**：用自己的话转述；单条引用不超过 30 字；
- 信息缺失写「原文未说明」，不编造；
- 事实句尽量带 `[p.N]`；页码可点回原文；
- 只用本文原文与元数据，不引入外部知识；
- 精读是卡片之外的独立产物，不改七段卡；
- 后台任务串行，失败显式；重跑覆盖精读缓存。

### 6.13 论证链（P4.10）

写作最缺的不是摘要，而是一个能直接放进正文的**论证单元**：一句可辩护的论点，加上支持它、反驳它、限定它的原文证据。

```
精读论点 / 解析稿段落 / 右栏证据行 / 研究问题
  → 建链弹窗（仍在论文库，不切写作）
  → 确认 claim + 节点（支持/反驳/限定/推导/对比）
  → 保存到 chains/<id>.json
  → 弹窗底部选文稿插入：生成带 [[p#^q|作者 年, p.N]] 的段落
```

四种建链方式：

| 方式 | 输入 | 系统做什么 | 用户做什么 |
|---|---|---|---|
| **论点先行** | 精读的结论/创新点/局限/核心要点，或自己写一句 | 从该句所在板块的引用与同页证据里提候选节点 | 勾掉不相关证据、改关系、保存 |
| **证据先行** | 引用库选 1–N 条证据 | 调模型提议一句共同论点（无模型时给空位） | 改论点、确认、保存 |
| **问题先行** | 一个研究问题 | 跨论文检索证据，按论文去重后给候选节点 | 改论点、补/删节点、保存 |
| **原文段落** | 解析稿里点任意一段正文 | 取该段首句当论点草稿；该段还没有 q-id 时补一条证据（引文=段落原文，block=该段） | 改论点、保存或再补证据 |

规则：

- **AI 只提议，不落库**：论点、节点、关系都要用户确认；
- 节点必须来自库内已有 `q-id`，页码/块/引文从卡片证据复制；
- 一条链最多 12 个节点；无证据时明确提示「没找到可挂的证据」，不硬凑；
- 入口：精读论点、解析稿段落、右栏证据行、右栏「证据」tab 的「证据链」分段；全部打开**弹窗**，不切写作页、不新增顶级页签；
- 证据与已保存的链都落在右栏「证据」tab；新补的证据刷新后立即出现在计数里；
- 弹窗右侧是证据选择器：默认「本论文 N」列出卡片已有证据，点「添加」即可；可切「全库」跨论文搜索；已添加的置灰；
- 原文段落建链只允许正文，页眉页脚显式拒绝；补证据是用户点「建链」的显式动作；
- 插入文稿在弹窗内选择目标文稿（或新建），追加普通 Markdown 引用；反链、参考文献、导出复用写作链路；
- 链可重开、改名、删除；节点可跳 `p.N + block`。

### 6.14 证据链知识库（P4.10+）

「图谱」页首屏从概念图换成**证据链知识库**：

```
claim（论点） ──支持/反驳/限定/推导/对比──> evidence（q-id 引文） ──出处──> paper（论文）
```

- 数据只来自 `chains/*.json`，不重新抽取模型；同一 q-id 被多条链引用时图上汇聚为一个证据节点；
- 只要有链，**全库论文都上图**：有链论文正常显示，没链论文暗色虚线并计入「未建链 N」，避免误以为库里只有一篇；
- 用 **Cytoscape.js**（MIT，本地文件）渲染：节点可拖、画布可缩放/平移、拖动后自动保存坐标；
- 节点只显示 **≤10 字摘要**（论点取首句、证据显示 p.N、论文显示作者年），完整文本在右侧详情/悬停提示；
- 配色分三类：**论点蓝 / 证据绿 / 论文紫**；关系边按支持/反驳/限定/推导/对比分色；失效黄虚线；
- 布局存 `chains/.layout.json`（派生数据，可删）；新增链时保留已拖位置，新节点优先贴邻居；
- 搜索按论点/引文/论文标题过滤；点节点看右侧详情，可打开链、回原文 p.N + block、打开论文；
- 失效证据保留并标黄虚线；统计条显示链/证据/论文/失效数；
- 概念图、可比组、待归一队列保留为第二个视图「概念图谱」，不删除。

规则：

- 图是**只读视图**：建链、改链仍在弹窗；图上只做导航与布局；
- 不引入 CDN，图引擎走本地 `/api/litkb/vendor/cytoscape.js`，离线可用；
- 布局坐标只存节点 id → {x,y}，不存业务数据；删布局文件可重建。

## 8. 数据与隐私

- 所有 PDF、卡片、索引存放于**用户选择的本地文件夹**；
- 默认不上传整篇 PDF；模型调用只发送必要的文本片段（可在设置里收紧）；
- 模型凭据存宿主凭据系统，不写入库文件；
- 翻译只发送解析文本块，不发送页图；页图与块坐标本地生成、本地缓存；
- 卸载插件不删除库；删除库需要用户显式操作。

## 9. 非目标（v1.0）

| 不做 | 原因 |
|---|---|
| 移动端 | 使用场景在桌面 |
| 多人协作 / 云端同步 | 先服务单人，避免权限与冲突 |
| 浏览器插件 | 宿主没有公开插件 API |
| 自动下载付费文献 | 合规风险 |
| 替代 Zotero | 定位不同，可共存 |
| 自动生成完整论文 | 学术诚信 |
| 人工精校 / 出版级翻译 | 译文是阅读辅助，机翻标记常驻 |
| 默认 OCR 图内文字 | 需要时接外部解析器，不默认跑 OCR |
| PDF 编辑 / 批注写回 PDF | 批注只进 Markdown |
| 解析块手工纠错 | 会改变证据回链，需版本与校验设计；v1.1 再评估 |
| 三栏主屏（列表｜卡片｜PDF） | P3 评估后延后 P4：当前抽屉宽度已容纳卡片/解析稿，G4 不依赖三栏；重排风险大于收益 |
| PDF 页图文本层划词 | P3 评估后延后 P4：页图是 PNG，精确文本层需要逐字坐标与缩放对齐；本轮用「解析稿块 + 卡片正文」划选满足追问场景（带页码） |
| 图表号自动识别 | 证据只记页码 + 块 ID；图表号留 P4 |
| 概念手工新建/合并以外的图谱编辑 | P3 只做合并、改名、加别名、待归一队列；拖拽改图留 P4 |

## 11. 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 插件 API 变动 | 升级即坏 | 锁版本 + 冒烟测试 |
| PDF 解析质量 | 卡片空洞 | 质量评分 + 低分提示 + 可选 OCR |
| 归类错分 | 信任崩塌 | 低置信进队列、一键改、回流 |
| 图谱毛线球 | 功能变摆设 | 只画有证据的边、默认单主题 |
| 大库卡顿 | 体验崩 | 分页、懒加载、按需建图 |
| 模型成本 | 用不起 | 缓存、分层、批量 |
| 版面块坐标漂移 | 高亮错位 | bbox 按页宽高归一化；重解析后校验块文本哈希 |
| 双栏 / 公式 / 表格版面 | 阅读顺序乱 | 先按栏聚类；识别不了标 `low_layout` 并退化到页级 |
| 外部 OCR 依赖 | 装不上 / 超时 | 默认 pdf.js；OCR 仅扫描件显式开启，失败给原因码 |
| 翻译术语不一致 | 读起来别扭 | 术语表 + 译后校验；不一致的块标红可重译 |
| 编辑覆盖模型文本 | 改错难恢复 | 保存前备份到 `cards/.versions/`；可回滚上一版 |
| 状态随意改 | 状态不可信 | 用户自行负责；保留 statusHistory 可追溯 |
| 反链扫描慢 | 打开变慢 | 只扫 `cards/` 与 `exports/`，按 mtime 缓存 |
| 逐段重生成不一致 | 与全卡风格不一 | 只替换该段与其证据，不重排其他段 |
| 边抽取漏/错 | 图不可信 | 只收有 evidence 的边；丢弃计数显式；人工可重跑单篇 |
| 概念同义未合并 | 图谱分裂 | 别名表 + 待归一队列；合并后重建边 |
| 追问编页码 | 引用错误 | 只允许材料内页码；越界标红；无依据强制声明 |
| 可比组数值不可比 | 误导结论 | 只聚合同数据集同指标；显示年份与出处；不自动下结论 |

## 12. 术语

| 术语 | 含义 |
|---|---|
| 两个轴 | 大类（知网文献类型）/ 主题（扁平标签） |
| 标签 | 扁平的主题词，可增删，参考微信 |
| 七段卡 | 一句话、问题、方法、数据、结果、局限、与课题关系 |
| 证据块 | 带 `^q-xxxx` 的引文，可跳转、可反查 |
| 结构化覆盖率 | 有卡片且证据 ≥3 条的论文占比 |
| 可比组 | 同数据集、同指标的一组论文 |
| 闸门 | 阶段验收点，不过不进入下一阶段 |
| 解析块 | 解析稿里的一个版面单元（标题/段落/图注/表注），带页码与 bbox |
| bbox | 块在页面上的矩形，按页宽高归一化到 0–1 |
| 块锚点 | Markdown 里的 `<!-- b:xxxxxxxx -->`，用于回链版面块 |
| 对照模式 | 原文段与译文段并排显示 |
| 术语表 | 领域词 → 固定译名，翻译时强制 |
| 逐段重生成 | 只重写七段中的某一段，不重跑整卡 |
| 状态历史 | `statusHistory` 记录每次 from/to/at，不做顺序校验 |
| 块断链 | 证据指向的版面块已不存在 |
| 反链 | 某条证据被哪些卡片/草稿引用 |
| 范围翻译 | 摘要+结论 / 本章 / 整篇 / 单块 |
| 概念 | 方法 / 数据集 / 指标，进受控词表，有别名与待归一状态 |
| 边 | 论文或概念之间的受控关系，必须挂一条证据 |
| 待归一 | 抽取到但没把握合并的概念，人工确认前不进图 |
| 页码约束 | 追问回答里的 `[p.N]` 必须落在本次材料页码内 |
