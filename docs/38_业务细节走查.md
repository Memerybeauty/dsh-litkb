# 业务细节走查（v0.7.0 · 进行中）

| 项 | 内容 |
|---|---|
| 目标 | 不拓宽功能边界，把现有每个业务的入口、状态、文案、数据一致性逐块过一遍 |
| 方式 | 每块一轮：先列问题 → 当场修低风险项 → 需要决策的留到本轮末尾 |
| 顺序 | 论文库 → 横向精读/图谱/检索 → 研究工作台 → 写作 → 设置/标签/术语/导入 |

## 每块固定检查项

- 入口是否唯一、有没有重复/无效按钮；
- 空态、加载、错误、长文本、窄屏；
- 按钮尺寸/文案/危险操作确认；
- 数据一致性（列表与详情、统计与筛选、导出与当前筛选）；
- 已知欠账是否仍成立；
- 术语统一（“论文/文献”“证据链/论证链”“研究/主题”）。
