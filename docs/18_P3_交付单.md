## 2. 现在能做什么

| 面 | 能力 |
|---|---|
| 概念归一 | `concepts/concepts.json` 受控词表；`U-Net` / `UNet` / `u net` 归一为同一概念；旧名自动进别名；改名不换 ID |
| 待归一 | 拿不准的进 `pending`，不画进图；可合并到已有、改名、加别名、批准为新概念；合并后边自动重指并重建 |
| 边抽取 | 七段卡 + 证据 → 模型 → 四类边；每条边必须引用卡内已有证据，页码/块/引文从证据复制；`reports` 缺数字直接丢弃 |
| 增量/重建 | 有缓存默认跳过；`force` 重跑；串行任务 + 进度 + 丢弃计数 + 单篇失败不拖垮全局 |
| 图谱页 | 自绘力导向图（无新增依赖）；主题/年份/方法·数据集·指标/名称搜索过滤；节点/边点击详情；证据跳页 |
| 可比组 | 聚合 `reports`，按数据集 + 指标分组；同篇取最新；数值降序；表格含论文/数值/年份/证据 |
| 划词追问 | 解析稿块或卡片正文选中 → 「追问」→ 回答断言带 `[p.N]`；点页码跳页 |
| 页码校验 | 材料页码白名单；越界页码不计引用、前端标红；无有效引用警告「回答未标注页码」；没依据强制说「原文没有足够依据」 |
| 存批注 | 追问答案一键写入「我的批注」 |

### 4.1 v0.5.2 修复：点边 p.N 不高亮

现象：从图谱边点 `p.N` 能翻页，但没有像 P2 卡片那样高亮版面块。

原因：边是从**原始卡片 JSON** 抽的，旧卡片的 `evidence[].block` 为空；P2 的卡片读取会在内存里按页 + 引文回贴块，图谱没走这一步。

修复：

- 构图时：抽完边立刻按页 + 引文回贴版面块，写进 `edges.jsonl`；
- 读图时：对**已存在的旧边**再补一次（不改盘），所以不用重建图谱也能高亮；
- 增量构建时：顺手把旧分析缓存里的空 block 补上，回写 `cards` 之外的 `concepts/papers/*.json` 与 `edges.jsonl`；
- 匹配增强：表格块先去 `<td>/<tr>` 标签再归一；跨块引文退到前缀，落到引文起始块；
- 仍找不到块（该论文没有解析稿）时，边详情显示「仅到页」，不再假装有高亮。

当前库实测：`p-1e4cbf07` 13/13 条边、`p-77c47bf9` 8/8 条边都有块；
另 2 篇没有解析稿，边只能到页（与 P2 一致）。

## 5. G4 验收怎么点（约 3 分钟）

G4 已按下面步骤验收通过；后续回归可照此复点。重启 DSH 到 **0.5.2**，刷新页面，打开「文献库」：

1. **图谱页**：图谱已有 47 条边，重启后直接打开即可（不用重建）；切主题/年份/类型过滤，图会变。
2. **点一条边**：右栏显示类型、论文、引文、页码；点 `p.N` 打开页图并高亮块；无解析稿的论文会显示「仅到页」。
3. **可比组**：切「可比组」→ 选一个数据集+指标 → 表格出现论文/数值/年份；点证据页码跳原文。
4. **追问**：打开任一篇的「解析稿」或「七段卡」→ 划选一句 → 点浮动「追问」→ 问「它和 baseline 差在哪」→
   回答里 `[p.N]` 可点；故意问材料外的内容，应回答「原文没有足够依据」。
5. **待归一**（如有）：图谱页右上「待归一 N」→ 合并/批准 → 回图看边是否正确。
