## 一、一页结论

1. **测试分五层**：单元、路由、界面结构、真实库干跑、回归样本。只做单元测试会漏掉「页码错、点击不跳、装机 404」。
2. **界面用结构断言，不靠肉眼**：抽屉必须有标题与关闭、图谱必须有高度、下拉必须限高——每个修过的 bug 都补一条。
3. **真实库审计比测试更硬**：47 条证据边逐条点开核对，47/47 合法；这是「能交付」和「测试全绿」的分界线。
4. **指标翻过一次车**：eval 首跑可定位 54%，根因是脚本核对范围错；修后 100%。评估脚本本身也要被 review。
5. **五个真实 bug 都有根因与回归**：定位祖先、类名冲突、双入口、高度链、溢出裁切——全是结构问题，不是算法问题。
6. **质量门是一条命令**：`npm run verify`（check + lint + format + test）+ coverage（70/65），CI 跑同一条链。
7. **缺口明确**：30 篇人工语义评分、12 个工具的真实对话端到端、多分辨率截图矩阵，都还没做。

## 二、五层测试

| 层 | 测什么 | 怎么做 | 例子 |
|---|---|---|---|
| 单元 | 纯函数、规则、边界 | 临时目录 + 直接 import；断言输入输出 | 链去重、段落合并、页码校验 |
| 路由 | 请求/响应/错误码/幂等 | 临时库，直接调 handler | 备份校验、恢复 428/413/422 |
| 界面 | 结构/文案/类名/状态 | DOM/字符串断言，不依赖浏览器 | 抽屉有标题、图谱有高度、下拉限高 |
| 真实库 | 端到端 + 真实脏数据 | 复制真实库跑脚本，逐条审计 | 47 条边逐条核对 |
| 回归 | 改动不破坏既有 | 每次改规则/prompt 先跑标准样本 | 3 篇标准卡（计划中的基线） |

**原则**：

- 每修一个 bug，补一条能复现它的断言；
- 测试通过 ≠ 功能可用：还要在真实宿主里点一遍；
- 测试数据不冒充真实数据；真实库样本量写清楚。

## 五、业务细节走查

**目标**：不拓功能，只过一致性。**顺序**：论文库 → 横向/图谱/检索 → 工作台 → 写作 → 设置。

每块固定 6 项：

1. 入口唯一、无重复/无效按钮；
2. 空态/加载/错误/长文本/窄屏；
3. 按钮尺寸/文案/危险操作确认；
4. 数据一致性（列表/详情、统计/筛选、导出/筛选）；
5. 已知欠账是否仍成立；
6. 术语统一。

**产出**：走查表（检查项/现状/处理）。v0.7.x 的「导出收进菜单」「审核队列文案」「DOI 判重」「任务取消/续跑」都来自这里。

## 六、五个真实 bug 的根因与回归

### 6.1 v0.4.4 · 解析稿定位 ScopeError

| 项 | 内容 |
|---|---|
| 现象 | 点解析稿段落，定位报错，右栏不联动 |
| 根因 | 定位逻辑在跨作用域取变量，运行时抛 `ScopeError` |
| 修复 | 收敛变量作用域，统一走定位函数 |
| 回归 | 补「点击段落 → 右栏高亮」用例 |

### 6.2 v0.6.1 · 抽屉标题被卷走

| 项 | 内容 |
|---|---|
| 现象 | 页面滚动后抽屉像「没有头」，内容从第 5 节开始 |
| 根因 | 抽屉相对可滚动的 `.litkb-body` 定位，标题随内容滚出视口 |
| 修复 | 工作台页设为定位祖先；抽屉固定头、内部滚动；宽度收到 `min(720px,100%)` |
| 回归 | 断言「抽屉必须有标题与关闭」「工作台页必须是定位祖先」 |

### 6.3 v0.8.2 · 链编辑器右侧塌成 14px

| 项 | 内容 |
|---|---|
| 现象 | 「添加证据」面板变成竖排文字，整体错位 |
| 根因 | 面板与后加的复选框共用 `.litkb-chainPick` 类，后置规则把面板宽度压成 14px |
| 修复 | 复选框改名 `.litkb-chainCheck`；面板恢复 340px |
| 回归 | CSS 断言：面板宽度、类名不复用 |

### 6.4 v0.9.1 · 解析页建链仍是旧行为

| 项 | 内容 |
|---|---|
| 现象 | 卡片页已改成「证据优先」，解析页选区建链仍把句子当论点 |
| 根因 | 只改了卡片页入口，漏了解析页；同一动作有两个入口 |
| 修复 | 解析页改用 `buildFromSelection`：先落 `kind=selection` 证据，再开链 |
| 回归 | 源码断言：选句不得写进 claim；两个入口共用同一函数 |

### 6.5 v0.11.1 · 图谱空白 + 下拉被裁

| 项 | 内容 |
|---|---|
| 现象 | 图谱页画布高度 0；「从标签建」下拉被页面裁切 |
| 根因 | 图谱页不在 flex 高度链里，`height:100%` 解析为 0；工作台页 `overflow:hidden` 裁掉浮层 |
| 修复 | 论文库→图谱给 `.litkb-body` 加 `is-graph`，三层确定高度；工作台页 `overflow:visible`，菜单限高内部滚动 |
| 回归 | CSS 断言：高度链、菜单限高、不得裁切 |

**五个 bug 的共同点**：都能用「结构断言」防住，不能靠「再看一眼」。

## 九、结论

质量不是「测试全绿」，是**三层证据**：
自动化（136 项 + 覆盖率）、真实库（47/47 边）、真实宿主（装机点主路径）。
这三层都过，才敢说「可交付」；只过第一层，就是「代码看起来没问题」。
